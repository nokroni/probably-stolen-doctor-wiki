## Source checks and transfer paperwork

| Action | How the chart uses it |
| --- | --- |
| Disconnect power cable or isolate a service port | Use the visible bedside hazard action or **Source / transfer** when the chart requires it. Stabilize and reassess once the game marks the source isolated. |
| Read the exposure label, badge, or container | Open the indicated exposure object. **Seal exposure kit** is offered on applicable charts. Compare the record with the symptoms and the witness before choosing a treatment. |
| Ask the witness and file property | Use the available question at the top of the chart or in **Diagnostics**. In **Source / transfer**, file the badge, property or exposure option that matches the observed evidence. Document uncertainty when the chart offers it. |
| Test tap-water sample | Use the available bedside test with a fresh Water Test Strip in owned stock. The game files the result for the crew. |
| Read Referring chart or request Medbay scan review | Open the prior readings or strips to build the current chart. A scan review can supply extra evidence where offered. The actual handover is a separate action. |
| Compare findings and file a report | When paperwork is requested, gather the site findings and witness account, then compare the requested readings. Review which findings or signed copy will go with the patient before choosing the report option. |
| Transfer options and Move to cot | Check whether the chart offers a staffed crew, an approved shuttle, or local care. Discuss payment separately if the patient can. When the game offers **Move to cot**, finish the required monitoring and transfer checks. After the move, repeat the indicated exam, cuff, and breathing checks. |
| Practice, book, or cancel a dispatch | At an empty Grade IV bedside, cycle the title at the top to browse available dispatches. Read the stock and equipment requirements. Use **Practice call** when the listing requires a rehearsal, then **Book dispatch** when eligible. Use **Cancel booking** to change an existing appointment while that control is available. |

## Observation, closure, and follow-up

- **Discharge patient.** Complete the required care, diagnosis, observation and rechecks. The local discharge control turns green when the chart is ready. A minor case can finish without measurements the chart does not need.
- **Call Medbay and Hand over to Medbay.** Call on eligible visits that need further help. Keep the patient supported until the crew arrives. Finish the current handover checks, or use **Ask crew to take over** when the case offers that alternative. On a local-only visit, use the available bedside care and complete its observation.
- **Watch the change after treatment.** A new symptom or genuine deterioration interrupts the observation window. Treat the cause, confirm the relevant findings again, and allow a fresh watch to finish. If a signal drops out, check the probe or line and the patient before deciding what changed.
- **Complete specialist and post-operation checks.** In the available ward panel, request and file any required record, compare the marked observations, and finish the offered rehearsal before using specialist equipment. Once a procedure is running, verify pulse, breathing and the probe after a move. **Confirm transfer checks**, **File recovery check**, and **Sign completed observation** require the current findings shown beside them. If a fresh cuff expires, measure again. **Abort procedure** opens a confirmation when available.
- **Close consultations and visits.** Confirm any eligible deferred consultation, read the receipt, and return to the counter for the reply. Check the disposition before starting another appointment.
- **Open Case review or Recent cases.** Use the timeline filters, open a retained exam, and compare recorded strips and the timing of treatment. Read an authorized **Signed ward update** when it appears. At a follow-up visit, ask about changes and repeat the requested finding before signing or arranging more care.
