## Source checks and transfer paperwork

| Action | How the chart uses it |
| --- | --- |
| Disconnect power cable or isolate a service port | Use the visible bedside hazard action or **Source / transfer** when the chart requires it. Stabilize and reassess once the game marks the source isolated. |
| Read the exposure label, badge, or container | Open the indicated exposure object. **Seal exposure kit** is offered on applicable charts. Compare the record with the symptoms and the witness before choosing a treatment. |
| Ask the witness and file property | Look for the available question in the chart's **History** tab or in **Diagnostics**. In **Source / transfer**, file the badge, property or exposure option that matches the observed evidence. Document uncertainty when the chart offers it. |
| Test tap-water sample | Use the available bedside test with a fresh Water Test Strip in owned stock. The game files the result for the crew. |
| Read Referring chart or request Medbay scan review | If the visit offers **Referring chart**, open it to compare readings and ECGs taken before arrival with your bedside checks. Some charts also let you request a Medbay scan review. Use the separate handover control when the visit calls for one. |
| Compare findings and file a report | When paperwork is requested, gather the site findings and witness account, then compare the requested readings. Review which findings or signed copy will go with the patient before choosing the report option. |
| Transfer options and Move to cot | Check whether the chart offers a staffed crew, an approved shuttle, or local care. Discuss payment separately if the patient can. When the game offers **Move to cot**, finish the required monitoring and transfer checks. After the move, repeat the indicated exam, cuff, and breathing checks. |
| Practice, book, or cancel a dispatch | At an empty Grade IV bedside, cycle the title at the top to browse dispatches. If a dispatch shows **Practice call**, complete its rehearsal before booking. Once you unlock [Ward overflow referrals](../../systems/referrals/), select **Ward overflow** and **Book dispatch** to get a case that fits your equipment and stock. To change an existing appointment, go back to its entry and choose **Cancel booking**. |

If both rides are available, check whether the patient needs monitoring on the way. The shuttle has no monitor. If new symptoms appear, reassess the patient and check whether the original transport plan is still available.
