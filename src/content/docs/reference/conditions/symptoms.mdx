If the patient collapsed, check the wrist and chest movement first. [Heart rhythms and cardiac arrest](../rhythms/) covers what the game offers when the pulse is absent. If the chest barely rises but a pulse is still felt, start with [Breathing problems](../breathing/).

On a stable patient, use **Body exam** and **Exam findings** to locate the clue. Select the site or ask a follow-up question in the intake. The **Me** box can point you to the next available control.
