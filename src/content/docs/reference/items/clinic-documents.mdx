---
title: "Clinic papers and license"
description: "Find the license plate, handbook, and File Box documents."
---

Open the File Box to read the handbook again. If patients stop coming, check that the current license plate is in the display case and that your clinic can accept new admissions.

## Items and sources

| Item | Use and source |
| --- | --- |
| Doctor license plate | Issued when the clinic starts. Place the current plate in the shop display case to receive patients from the second day onward. Ask the licensing officer for a Grade I replacement or the medical supplier at higher grades. |
| How to Be a Doctor | Illustrated handbook issued at the start. Store it in the File Box and open it when you need to find a control. |
| Clinic records | As you progress, you can file three clinical documents in the File Box, including a case note, a recovery record, and an overnight observation log. |
