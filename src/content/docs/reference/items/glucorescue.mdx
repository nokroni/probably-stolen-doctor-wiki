Take a fingertip reading with a fitted Glucose sampler. When the current result supports GlucoRescue, select an eligible forearm, confirm the pack and syringe, and give the game dose. Glucose changes gradually. Take another reading before deciding whether treatment has worked.

## Crafting recipe

**Ingredients and vessels**　1 Sugarpod kernel, 1 clean Water Pitcher, and 1 piece of Kotton Fabric. For a refined extract for compound crafting, also prepare 2 mL of Sterile Clarifier.

1. Blend the kernel into a clean 25 mL graduated cylinder to collect **Sugarpod sap**. For a refined batch, add two full 1 mL draws of Sterile Clarifier.
2. Fit the cylinder on the Heating Plate and start on **Low**. If the actual temperature stays below **65 °C**, switch to **High**. Remove the cylinder when **Clarified Sugarpod** and debris appear. Batches made with the clarifier also show **Refined Sugarpod**.
3. Fit **Kotton Fabric** into the clean pitcher and pour the heated mixture into it. Heating creates the debris, so wait for the reaction before filtering. Inspect the filtered liquid. If it still contains debris, fit fresh fabric and filter again.
4. Fit **the pitcher holding the filtrate** in the [Chem Finisher](../chemistry-tools/) and select **GlucoRescue extract**. Each output uses 2 mL.
5. Check that the extract is ready to seal. One accepted extract makes **2 GlucoRescue packs** at the [sterile finishing bench](../sterile-bench/). For [Epinephrine](../epinephrine/), set the extract containing Refined Sugarpod aside for the compound recipe.
