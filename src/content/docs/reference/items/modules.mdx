---
title: "Native equipment modules"
description: "Use the original module system in compatible top-model clinic devices."
---

The M4, manual defibrillator and station control module accept compatible native universal modules. Open the fitted device's module bay and read the displayed total after placement. Lower models run at their factory settings. Look for **Remove old modules** if a saved lower model still has legacy parts.

## Items and sources

| Base-game item | Clinic use |
| --- | --- |
| Performance Module, Overclock Module | Native performance effects can speed up device operations. Check the native module's power trade-off. |
| Efficiency Module, Eco Module | Native efficiency effects change energy draw. A stock manual charge costs selected joules ÷ 50. |
| Quality Module, Streamlining Module, Refinement Module | Use the module's displayed native modifiers. Higher quality improves the manual defibrillator's chance of converting an eligible rhythm and helps the M4 acquire signals. |
| Neural Core Module (Capped), Neural Core Module (Uncapped) | Apply their native performance, efficiency and quality modifiers when fitted to a compatible bay. |
| Ruined Module, Corrupted Module, Node (Small), Node (Medium) | The native module bay handles fitting and any effects. Check shape, tags and the native tooltip before buying. |
