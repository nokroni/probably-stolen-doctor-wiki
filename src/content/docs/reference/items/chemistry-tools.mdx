Unlock both Farmer and Chemist to access the clinic extract recipes. Use the preparation steps on the extract's own item page. The Chem Finisher uses 2 mL per output. Choose **Configure**, select the recipe, and check the vessel before **Output**. When a dry recipe is required, an apparently hot vessel can still contain water. Wait for the item description to lose its Water row.

## Items and sources

| Base-game item | Clinic crafting use |
| --- | --- |
| Blender, 25ml Graduated Cylinder, 50ml Graduated Cylinder and 100ml Graduated Cylinder | Turn produce into a measured mixture. The cylinder tooltip lists its contents, including leftover water. |
| Heating Plate and Chemical Equipment Module | Heat fictional crop mixtures. Native chemical modules change the plate's operating range and performance. |
| Evaporator | Separates the dry residue into its original container and collects liquid in the distillate container. |
| Chem Finisher | Turns prepared mixtures into named extracts. For a dry recipe, inspect the prepared vessel for residual water before finishing. |
| Water Pitcher and Kotton Fabric | Fit the fabric as a filter and collect the prepared Sugarpod mixture in the pitcher. |
| 1ml Dropper, 5ml Dropper, Bottle of Acidic Solution, Bottle of Basic Solution and Chemical Supplies (Common) | Measure game reagents in the cylinder. Open the native chemical supplies for reagent stock. |
| Chemistry Manual and Hydroponic Farming Manual | Explain the original machine controls and growing system. |
