**Cuff.** At an eligible upper arm, choose **Open pressure cuff → Wrap cuff → Measure cuff BP**. You can work elsewhere while it cycles. M4 offers **Auto cuff** and **Stop cuff cycle**.

**Arterial line.** With the transducer and a compatible powered monitor fitted, select an eligible forearm or open **Diagnostics → Connect / zero ART**. Compare the live ABP with the last cuff result. When a chart asks for a fresh cuff measurement, run the cuff again.

## Items and sources

| Item | Grade | What it does |
| --- | --- | --- |
| Pressure cuff | I | Wrap around an upper arm and start a reading. The cuff uses monitor power. Repeat it when the chart needs a fresh pressure. |
| Arterial transducer | II | Connect and zero the line for continuous arterial blood pressure on a compatible monitor. Uses monitor power. |
