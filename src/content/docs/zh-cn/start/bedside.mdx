## 先看看病人

病情平稳时，点底部的**全身检查**。约 **2.5 秒**后，打开**病例 → 检查结果**，就能看这次查到的情况。想看某一处或做局部操作，直接点病人身上对应的部位。分不清左右时，看看选中后显示的部位名称。处理后再查一次，看看有什么变化。

遇到紧急情况，先做游戏提示能做的急救操作。拿不准下一步时，看看左下角方框里的**我**。那是医生自己的判断，有时会提醒你哪个部位还没看，或哪项读数该复查了。

| 选择部位 | 可以找哪些操作 |
| --- | --- |
| 头部 | 接上呼吸囊面罩，或量体温。 |
| 胸部 | 接心电导联、开始按压，或点**贴上胸部电极片**，按编号对准轮廓。两根线都接好后，点床边的 AED 或手动除颤器打开操作面板。 |
| 手或前臂 | 摸脉时，两处都可以选。手部还可以接血氧指夹或查指尖血糖，前臂则能找给药和输液相关操作。 |
| 上臂 | 绑袖带测压。袖带开始充气后，可以先处理别处。 |
| 受伤部位 | 看检查发现，再做适用的伤口或关节操作。处理只作用于选中的部位。 |

监护仪上的心电和心率在一起，脉搏波和血氧在一起，袖带血压（NIBP）显示最近一次测量结果。更多波形需要相应设备和已接好的探头。听到心电声说明监护仪看到了电活动。想知道脉搏有没有回来，要实际摸一下手腕。[监护仪上的波形和数字怎么看](../monitor/)。

想用哪台设备，就点画面里的那台。可做诊断检查时，点床边的柜子打开**床旁仪器**。输液或输血时，点输液泵或输血台。空床时，用**打开床旁器材架**安装设备、查看供电。

<Aside title="空格键按一下，就按压一次">

在胸部开始心肺复苏后，按一下、松一下 **空格键**。两次按压之间可以用鼠标接导联、夹探头或拿其他器材。要停手动按压，直接点底部的**停止按压**。打开除颤器时也能看到这个按钮。

</Aside>

## 翻看病例

点床边的夹板，打开独立的全屏病例页。中间竖放的文件夹有四个分页。

| 分页 | 能看到什么 |
| --- | --- |
| **病史** | 送诊记录、就诊病史，以及可向病人或目击者询问的问题。 |
| **暴露记录** | 已记录的用药、接触电源等情况。有线索时可以在这里核对。 |
| **检查结果** | 全身检查查到的各处情况。可以点的结果会带你回到对应部位。 |
| **诊疗记录** | 初步诊断，以及按时间记下的检查、给药和其他处置。 |

线索够了，可以在病例里点**记录诊断**。点**关闭**或按 **Esc** 回到床边。正在进行的操作仍可用底部的按钮停止。

## 快速找到药

点床边的药盘就能找现有库存，也可以从一侧前臂打开适用的给药选项。需要从前臂给药时，在药品面板顶部选给药侧。给药前看清药名、这批药的纯度和价格。多批药怎么选、药品怎么翻页，见[药品和耗材](../../reference/procedures/medicines/)。空床时，在**设置急用操作**里固定一个常用动作，接诊时就能用**急用**直接打开。按钮没亮时，看看是否缺药、缺设备，或需要先补一次检查。

打开药品面板不会扣耗材。确认给药后就会用掉这份药和对应的注射器，即使这剂没起效也一样。可以先救人，再记录或者修改初步诊断。

## 什么时候可以结案

| 病人的情况 | 床边怎么收尾 |
| --- | --- |
| 可以回去休养 | 完成处理和观察，记录初步诊断。等**办理离诊**变绿再签字。简单轻伤通常不用专门量血压或摸脉。 |
| 需要进一步救治 | 这个病例允许转运时，点**呼叫医疗舱**。人还在床边，接应途中也照常治疗和复查。等接应到了、交接条件满足，点**转交医疗舱**。 |
| 这单需要留在店里完成 | 看接诊单的要求，继续床旁处理。观察中出现新症状或病情变差时，先重新稳住病人，再开始算新一轮观察。 |

结案按钮在床旁底部。按钮没亮时，看看当前提示或留观倒计时。诊断还没记录、需要复查、接应人员仍在路上，下一步各不相同。

预约需要查血糖的病人时，器材架上得装好血糖仪。如果预约后才取下血糖仪，其他器材和物资齐全时，有些病人仍能接诊。做完**全身检查**，在病例的**病史**页问清发病经过，再点病人的手。看到**无法测血糖，转诊**时，可以请医疗舱接应。结合已经查到的线索记录初步诊断，病因还拿不准就记**病因待查**（病历有这一项时）。等病人平稳、做完必要的复查、接应到场，再点交接。

结案后打开**病例复盘**，就能在一条时间线上查看检查、治疗和结局。点其中一条检查记录，可以回看当时查到的情况。
