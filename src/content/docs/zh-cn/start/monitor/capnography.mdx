title: 呼气末二氧化碳怎么看
description: 看 EtCO₂ 数字、呼吸频率和波形形状，判断下一步查哪里。
---

**EtCO₂** 是一次呼气快结束时测到的二氧化碳分压，单位是 **mmHg**。呼吸平稳的成人常见参考范围为 **35–45 mmHg**。二氧化碳读数会受通气和肺部血流影响。附近的 **RR** 是每分钟呼吸次数。一次呼气通常会画出上升、平台和回落这几段。[呼气二氧化碳测量参考](https://www.ncbi.nlm.nih.gov/books/NBK539754/) · [美国呼吸治疗协会指南](https://www.aarc.org/wp-content/uploads/2014/08/04.11.0503.pdf)

装好并供电的 **M4 和呼吸机** 支持二氧化碳采样。点床边的呼吸机，接上 CO₂ 采样管。可以先让机器只采样病人的自主呼吸。等一次完整的呼气画出来，再看读数。

| 游戏里看到的变化 | 接下来查哪里 |
| --- | --- |
| 斜着爬升，像鱼鳍 | 想到气流受阻。查看胸部，结合喘鸣、呼气是否费力和病人说的症状。 |
| 波形又短又密 | 呼吸可能又浅又快。对照胸部两侧的起伏和听诊发现，顺手查体温和血氧。 |
| 平台还在，但整体变矮 | 看呼吸的同时也查脉搏和血压。送到肺里的血流不足，也会压低这个数。 |
| 数字偏高，呼吸变慢 | 查胸廓有没有起伏、呼吸是否够用。有设备辅助时，看看面罩和管路。 |
| 波形突然消失或只剩破折号 | 马上看病人是否还在呼吸，再检查管路和面罩。重新接管后，要等到一次完整呼气才有新数值。 |
| 按压时上升，或有一次明显的持续上升 | 可能是送到肺里的血流变好了。结合手腕脉搏和血压复核，确认病人自己的循环是否回来。 |

单次读数会变，看前后几次呼吸更有用。按压中的数值也受通气、按压效果和血流影响。[美国心脏协会成人高级生命支持指南](https://cpr.heart.org/en/resuscitation-science/cpr-and-ecc-guidelines/adult-advanced-life-support/)
