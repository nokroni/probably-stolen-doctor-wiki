## 种诊所药材

自制诊所药品需要农夫和化学家两项手艺。可在王尔德的人脉网里找退休农夫和退休化学家学。开档自带其中一项手艺时，只需再学另一项。制药流程搭起来之前，可以先向药商买成品。

给原版**水培机**加水并通电，就能种脉藤、月苔、霜藻或糖荚。过夜后检查长势和收成。留种会继承原版性状，优点和缺点都能传下去。这些种子也能用原版的作物基因工具处理。

## 从收成到药包

下表说的是游戏里的虚构原料和机器配方。准备干净量筒、搅拌机和原版化学设备。拆开一份**医疗用品**（普通或限制级），可以取出一瓶**无菌澄清液**和一瓶**脉稳载液**。如果要做无菌药筒，另外留一份未拆封的。

| 做哪种药的提取物 | 游戏内加工步骤 |
| --- | --- |
| 广谱抗感染包 | 打碎月苔，加入酸性溶液，再加热。正确配料时，加入无菌澄清液能改善成品。 |
| 补糖包 | 打碎糖荚并加热，再用干净韧棉织物滤掉残渣。可以额外加无菌澄清液。 |
| 补液包 | 把霜藻和糖荚一起打碎，在蒸发器里留下干料。也可先加入脉稳载液，形成霜藻盐后再蒸干。 |
| 循环支持包 | 打碎脉藤，加入碱性溶液后加热。正确配料时，可用脉稳载液精制。 |

用**化学成型机**选对应提取物，取出成品检查批次。通过检验的提取物可以在**无菌配制台**封成两份药包。配方要求干料时，确认容器里残留的水已经去掉。游戏内的用量和温度见手册和物品提示。

两条霜藻可做两支无菌注射器。高纯度循环支持包可以做**舒痛片**。四级还可用它和原版的罗非鱼皮移植物做**诊所生物凝胶**，或搭配补液包制成**肝素**。各配方所需纯度可在配制台查看。

## 配制复方药

复方药要用两份通过检验的对应提取物，以及一整瓶指定试剂。成品纯度取两份提取物中较低的一个。四级时，一份未拆封的普通或限制级医疗用品可以做两个**无菌药筒**。

| 复方药 | 执照要求 | 除循环支持剂提取物外还需要 |
| --- | --- | --- |
| 升压桥接剂 | 三级 | 补液剂提取物、一整瓶无菌澄清液。 |
| 稳律缓冲剂 | 四级 | 抗感染药提取物、一整瓶脉稳载液、一个无菌药筒。 |
| 肾上腺素 | 四级 | 补糖剂提取物、一整瓶无菌澄清液、一个无菌药筒。 |

给药时，可在床旁查看这一批药的纯度和当前起效概率。如果用药没起效，先复查病人，再看更新后的概率，决定要不要补一剂。

## 电源和模块

电动设备使用原版的**能量电池**。兼容设备也可以装原版**电流转换器**，要留意开关、供电费用和停电。四级可把装好电池的**医疗电源总站**放进同一个器材架。其他机器先用总站的电，供不上时再用自己的电源。

**M4**、**手动除颤器**和**工作站控制模块**能装原版模组。选购前可查看[每台器材的模组属性](../../items/modules/)。接诊前，在机器的模组槽和器材架上检查设备是否准备好。
