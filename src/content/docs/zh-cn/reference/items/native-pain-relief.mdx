title: "原版止痛针剂"
description: "查看奥克西莫与奥克莫吸在游戏内监护止痛中的用途。"

这些针剂沿用原版买卖及其他获取渠道。二级起，检查伤处、接好心电和指夹，再点可用的前臂，在**药品**里选符合条件的针剂。病人说过的不良反应和现在的呼吸情况会影响选择。用药后复查不适和呼吸。

## 物品与来源

| 原版物品 | 诊所用途 |
| --- | --- |
| 奥克西莫注射器 | 二级起可在监护下给检查过的特定伤情止痛。接好心电导联和指夹，用药后留意呼吸。 |
| 奥克莫吸注射器 | 二级起可作为监护下的止痛选项。沿用原版获取渠道。 |
