同时解锁农夫和化学家后，才能使用诊所提取物配方。按对应提取物页面的步骤准备。化学制剂成型机每出一份成品用 2 mL。先点**配置**选配方，检查容器，再点**出料**。做干料时，量筒热了也可能还有水，要等物品详情里不再显示水的成分。

## 物品与来源

| 原版物品 | 在制药流程中的用途 |
| --- | --- |
| 搅拌机、25 毫升量筒、50 毫升量筒、100 毫升量筒 | 将作物加工成可量取的混合物。量筒的提示会列出成分和残余水量。 |
| 加热板、化学设备模组 | 给游戏内的作物混合物加热。原版化学模组可以改变机器档位和加热表现。 |
| 蒸发器 | 原容器留下干燥残留物，馏出液收进另一只容器。 |
| 化学制剂成型机 | 把处理过的混合物制成提取物。干料配方要等容器成分里的水消失后才能出料。 |
| 水罐、韧棉织物 | 在罐里装滤布，过滤处理过的糖荚混合物。 |
| 1 毫升滴管、5 毫升滴管、酸性溶液瓶、碱性溶液瓶、化学用品（普通） | 用滴管在量筒里添加定量试剂。拆原版化学用品可补充试剂。 |
| 化学手册、水培农业手册 | 查原版机器操作与种植规则。 |
