解锁农夫和化学家后，化学制剂成型机会显示诊所提取物配方。每种药的用量和温度见[制药配方索引](../../systems/production/)。下面是四种提取物共用的机器操作。

## 物品与来源

| 原版物品 | 在制药流程中的用途 |
| --- | --- |
| 成分光谱仪 | 核对原汁、精制成分和杂质各占多少。配复方前可以拿它看提取物里是否含指定成分。 |
| 搅拌机、25 毫升量筒、50 毫升量筒、100 毫升量筒 | 将作物加工成可量取的混合物。量筒的提示会列出成分和残余水量。 |
| 加热板、化学设备模组 | 给作物混合物加热。配方使用低档。若装了模组，以量筒的实际温度为准。 |
| 蒸发器 | 原容器留下干燥残留物，馏出液收进另一只容器。 |
| 化学制剂成型机 | 把处理过的混合物制成提取物。干料配方要等容器成分里的水消失后才能出料。 |
| 水罐、韧棉织物 | 在罐里装滤布，过滤处理过的糖荚混合物。 |
| 1 毫升滴管、酸性溶液瓶、碱性溶液瓶、化学用品（普通） | 用无模组的 1 mL 滴管量取。酸碱溶液用完可拆原版化学用品补充。 |
| 化学手册、水培农业手册 | 查原版机器操作与种植规则。 |

## 从搅拌到成型

1. 把干净空量筒插进搅拌机的容器槽，再把收成放进输入格，点**启动**。拿出量筒看物品详情，确认原汁和用量。不同配方分开做。
2. 按配方加试剂。无模组的 1 mL 滴管一满管是 1 mL，两满管是 2 mL。月苔和脉藤配方量的是原版瓶里的溶液体积。精制或结盐用的[诊所试剂](../clinic-reagents/)来自医疗用品。量完看成分栏，确认加进了正确的量筒。
3. 按对应配方加热，检查实际温度和新出现的成分。糖荚等清液出现后再过滤。补液剂用蒸发器处理，直到原量筒的成分栏里没有水。
4. 把处理好的容器放入成型机，点**配置**选对应提取物，再点**输出**。每份提取物用 **2 mL** 原料。一批可以多次出料，具体份数看容器剩余量。
5. 查看提取物详情。看到**这批纯度为 X%，可以封成两包药**，就可以拿去配制台。成型机的原版纯度栏只算配方指定的那种成分。诊所还把精制成分计入药效，所以给药时以封装提示和成品显示的纯度为准。

## 容器详情里的成分名称

| 成分名称 | 什么时候会看到 |
| --- | --- |
| 脉藤原汁、月苔原汁、霜藻原汁、糖荚原汁 | 作物刚搅拌，还没进一步处理时。 |
| 活化脉藤原汁、活化月苔原汁、糖荚清液 | 分别是[循环支持包](../pulselift/)、[广谱抗感染包](../broadguard/)和[补糖包](../glucorescue/)提取物所用的成分。 |
| 精制脉藤、精制月苔、精制糖荚 | 使用对应的诊所试剂后得到的成分。做相应复方时，配制台会检查提取物里有没有这些成分。 |
| 稳定霜藻盐 | 霜藻和糖荚混合物处理后的成分。把干燥残留物成型，得到升压桥接剂所需的[补液剂提取物](../clearflow/)。 |

## 出不了料或封不了包

| 看到什么 | 检查哪里 |
| --- | --- |
| 到了温度，月苔或脉藤还是原汁 | 核对加热板是否开启，以及酸、碱瓶是否拿对。温度看量筒实际读数。 |
| 补糖剂成型后提示过滤 | 先把糖荚加热出清液，再倒进装好干净韧棉织物的水罐。用接到滤液的水罐成型。 |
| 补液剂还出不了料 | 打开原量筒的详情。哪怕只剩少量水，也要继续蒸发。检查电池和空馏出液容器有没有装好。 |
| 还有试剂没反应 | 核对试剂种类和用量。精制用 2 mL，等混合物反应之后再出料。如果已经加热才补进试剂，用新一批原料重做。 |
| 成型了，但提示没过检 | 检查是否用了干净容器、是否混入其他液体，以及月苔和脉藤批次是否有过多剩余酸碱。补液剂还要核对两种作物的配比。 |
