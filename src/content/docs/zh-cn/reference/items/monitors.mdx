1. 把监护仪装到器材架上，接好有电的能量电池或兼容电源。
2. 点胸部，选择**接上心电导联**。指夹和血压袖带需要在各自的部位连接。
3. 先对照 ECG 与 HR，再看脉搏波和 SpO₂。NIBP 为最近一次袖带读数。M4 还为接好的动脉压和 CO₂ 设备预留独立通道。
4. M3 或 M4 波形清楚时，可点**保存心电**。放电后等扫描恢复，再摸一次脉搏。

探头未接时，对应通道会留空。需要保存心电或配合十二导联时可升级到 M3；要自动袖带测压与进阶通道，可换 M4。器材商会按购买等级带货。

## 物品与来源

| 器材 | 等级 | 用法 |
| --- | --- | --- |
| M2 床旁监护仪 | I | 入门监护仪。接好相应导联和探头后，可以看实时心电、脉搏血氧或测袖带血压。 |
| M3 诊断监护仪 | II | 可以保存短段心电图，供前后对比。 |
| M4 重症监护仪 | III | 支持自动袖带测压。接好配套设备后，可连续显示 ABP、EtCO₂ 等通道。可装原版模组。 |
