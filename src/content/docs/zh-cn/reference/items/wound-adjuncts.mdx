---
title: "伤口辅助用品与鱼类产物"
description: "在已检查的部位使用外用药、植皮片或符合条件的未受精鱼卵。"
---

符合条件的浅表伤口，选检查过的部位，再到**药品**或局部护理里找操作。用药膏、清洁用品或植皮片前先看选中的物品。这些和敷料各有各的使用条件。植皮罗非鱼产物来自原版水产养殖，受精卵留作繁殖，床旁列出鱼卵护理时用未受精的。

## 物品与来源

| 原版物品 | 诊所用途 |
| --- | --- |
| 南丁格尔软膏 | 检查过的浅表擦伤可以使用。 |
| 医用酒精 | 符合条件的浅表伤口可以选用，作外部清洁。 |
| 罗非鱼植皮片 | 用于符合条件的伤口护理，也是四级诊所生物凝胶的原料。 |
| 植皮罗非鱼卵 | 三级起可给检查过的擦伤用未受精鱼卵。受精卵留作繁殖。 |

涂完南丁格尔软膏，再做一次**全身检查**，打开**检查结果**看用药部位。病人能回答时，会告诉你擦伤没刚才那么刺痛了。伤口还在出血的话，继续处理出血并包扎。
