| 操作 | 游戏窗口里要做什么 |
| --- | --- |
| 加压止血 | 选已经露出的出血部位，点 **加压止血**。在圈里按住敷料，等进度环走满再松手。松手后环还是满的，伤口仍可能出血。就在这个窗口选一卷可用的绷带，包好再复查伤处。 |
| 清理松动碎屑 | 检查浅表伤口后，把窗口里松动的小碎片移到托盘。随后处理压力或敷料。较深或卡在伤处的异物有单独的操作。 |
| 包扎止血、包扎烫伤 | 点患处，用提示可选的绷带、烧伤敷料或**鱼皮敷料**。按住卷沿圈绕，进度条满了再松开鼠标固定。每次完成只处理选中的部位。再点病人身上刚包扎的地方，看看出血有没有变。 |
| 夹板固定 | 点已确认骨折的位置。把两段图示骨头拖进各自的轮廓，再把方形固定板放到接合处。一次处理一处，病历要求时复查血运。 |
| 关节复位 | 从已检查的部位打开操作窗，把圆形一端拖进对应的轮廓再松手。结束后检查提示的手掌或其他远端部位。 |
| 固定异物 | 在异物所在部位打开操作窗，把两块图示固定垫放进标好的位置。处理完复查伤处，根据病历准备后续诊疗或转运。 |
| 胸腔引流 | 三级以上、病历开放该操作时，选胸部。先完成要求的检查、超声、血压和支持，备一份无菌操作包。按窗口内的导向操作器具，接着推动滑杆。复查胸廓起伏和血压，残余出血可能还要另做处理。 |
| 自动修复、工具准备 | 在有记录的病灶处操作。先完成病历要求的扫描、血压和支持，确认无菌操作包与手术机电量。适用的表面修整可以用外科工具组辅助。等待机器完成，再看处理结果。 |
| 用手术机取出异物并封合 | 在已扫描且符合条件的部位操作，游戏会核对循环、近期血压、输血支持和电量。按窗口引导安装收集盒。异物取出和封合是两步。再测一次血压，根据病历封合伤处或交给转运队。 |
| 显微托架接合断指 | 在患手先**检查组织盒并征求同意**。条件齐备后，用有电的手术机、显微设备和无菌断指接合件。按托架图示操作，再点**检查指尖血流**。如果这份病历需要转运，包扎患手并把记录的组织盒一并交接。 |
| 肢体缺失时的处理 | 直接点残端所在的前臂或小腿，查看伤口并止血。其他伤处要分别处理。手部缺失时，把指夹接在另一只手上。按提示选还能使用的手臂绑袖带或输液。包扎后复测血压，交接时看清组织盒是否随病人移交。 |
| 瘢痕修整、标记或暂缓 | 检查患处并**征询患者意愿**。对方同意后再**标出瘢痕轮廓**。如果对方想改范围，按要求重做标记，也可**暂缓修整**。做**表面修整**前，标好范围、量一次血压，再备一份无菌操作包。库存里有外科工具套装时，可选 8 秒的辅助操作，常规操作用时 12 秒。机器停下后复查。病例复盘会分别记录画好的范围和完成的修整。 |
