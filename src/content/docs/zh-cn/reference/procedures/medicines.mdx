title: "药品和耗材"

---

在床边点**药品**，从可用的前臂打开**注射盘**，或用**床旁仪器 → 治疗托盘**。确认前看清批次、纯度和当前价格。用**设置急用操作**可以把常用药或绷带放在顺手的位置。某些药包还要配一支注射器。药没起效也会扣耗材，同一份病历再用这种药时，起效概率可能会上升。决定要不要补一剂前，先复查病人，再看更新后的概率。

| 操作 | 病历会核对什么 |
| --- | --- |
| 广谱抗感染包、补糖包、循环支持包和电解质支持 | 分别看有没有感染证据、测到低血糖、循环需要支持，或生化结果异常。给药后看效果，结案前复查相应的发现。 |
| 用补液包纠正已测出的电解质异常 | 按提示看治疗卡，完成床旁生化检查。病历提供电解质处置时，选择补液包批次。起效需要时间，等待读数变化时继续做所需的呼吸或循环支持。 |
| 纳洛通注射器 | 查阅暴露记录，确认病历支持这个用法。按钮亮起后才可给药。之后复查呼吸，继续观察。 |
| 肝素 | 在需要的病历里，先取得所要求的冠脉相关检查证据，然后到前臂确认给药，再跟进下一项操作。 |
| 升压桥接剂 | 三级药品，适用于病历允许、有脉搏且量到低血压的情况。选前臂给药，在支持期间复查血压和心电。 |
| 稳律缓冲剂 | 四级药品。快捷项会检查脉搏、近期血压、可读的心电和已记录的复发。起效后可以推迟下一次复发。即使波形有好转，也要再量血压。 |
| 肾上腺素 | 四级支持药品。病历需记录摸不到脉搏，或发现严重循环不良且持续。前臂操作可用时再选批次。之后继续所需的支持并复查循环。 |
| 原版止痛和局部感染用药 | **药品**里可能出现需监护的止痛针，或适用的噬菌霉素片。先问清楚、检查患处，并接好要求的探头。给药后留意呼吸和患处。 |
| 原版外用药和诊所生物凝胶 | 在已检查的部位，查看是否可以用药膏、医用酒精、鱼卵、鱼皮敷料或诊所自制生物凝胶。每种都有自己的库存与适用条件。一些病历还会提供资助方的蓝血。 |
| 安抚、商量康复和复诊用药 | 按病历提供的动作安抚病人、**给予舒痛片**或**商量戒断安排**。有些监护复诊会在沟通后开放相应药物。有的病历允许陪护，或在继续支持时请接应人员接手。 |
| 验真的维持用药 | 专科病历提供留存药品时，按可见按钮预订或领取。点**使用验真的免疫维持针**时，游戏会核对具体的可用针剂，然后记录这次用药。 |
| 离诊带药 | 符合条件的离诊可以开舒痛片或噬菌霉素片。先确认价格和库存，再签离诊。 |
