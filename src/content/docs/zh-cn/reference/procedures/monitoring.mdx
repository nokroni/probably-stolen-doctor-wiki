---
title: "监护和诊断仪器"
description: "连接传感器、做检查，并查看最新读数。"
---

| 操作 | 前置条件和读数 |
| --- | --- |
| 接上心电导联、检查接线 | 用供电正常的监护仪，在胸部接心电导联。已连接但信号差时，选**检查接线**。放电后等波形恢复，再结合新摸到的脉搏判断。 |
| 夹上血氧探头 | 装了指夹且监护仪有电时，选择一只可用的手。等脉搏波和血氧读数稳定。提示指夹松动时，在手部或**支持**里点**重新夹好指夹**，再对照手腕脉搏和呼吸情况。 |
| 打开血压袖带、绑上袖带、测血压 | 选可用的上臂，在袖带面板先绑好再启动。袖带开始测量后可以先处理其他问题。治疗或换床后，有些病历会要求再测一次。M4 还提供**自动测压**和**停止循环测压**。 |
| 量体温、接上体温探头 | 在头部打开体温计。手持体温计给出一次读数。装好体温监测设备并给 M4 供电后，可以接探头连续观察。点底部的**拔下体温探头**可以停止监测。 |
| 测血糖 | 装好血糖采样器，选可用的手或到**检查**里测量。等结果出来后再决定下一步。补糖后复测，如果握力或说话还有变化，把两次结果对照起来看。 |
| 采集十二导联、查看十二导联 | 可以点胸部，也可以点床边的柜子打开**床旁仪器**。需要装好十二导联记录仪和通电的 M3 或 M4，接上心电并保持信号。采集后打开报告，看结果和采集时间。 |
| 保存心电 | M3 或 M4 接上导联、波形清楚时，可以保存当前心电。处理后或者异常复发时，把前后的心电对照起来看。十二导联报告另行保存。 |
| 接动脉管并调零 | 装好动脉压传感器并给兼容监护仪供电。在前臂或**检查**里操作，等调零完成。动脉压实时波形起来后，可和最近的袖带读数、病人的情况一起看。 |
| 采集超声 | 在**检查**页选胸部、腹部或可检查的肢体，用有电的超声仪采集。报告会标出区域。病历要求看指定部位时，要选对地方。 |
| 生化检验 | 在前臂或**检查**页使用有电的床旁检验仪。按窗口的图示取样，再把样本放进分析槽。看完结果，再决定是否需要纠正异常。 |
| 接上、接回或拔下 CO₂ 采样管 | 装好已供电的 M4 和呼吸机，点床边的呼吸机接管。呼吸机停止通气时，采样管也能测到病人的自主呼吸。等采到完整的一次呼吸，再结合胸廓起伏看波形。拔管后该通道清空。 |
| 归档读数、标记血压情况 | M4 和抢救站控制器有电时，**归档读数**会保存当时的监护结果。如果病历提供**血压平稳**或**标记低血压**，先取得要求的读数，再按结果选。 |
