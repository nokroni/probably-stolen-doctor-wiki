| 操作 | 去哪里找，接下来做什么 |
| --- | --- |
| 辅助通气、调好面罩 | 装好呼吸囊面罩后，在头部或床边的快捷项启动。看胸口有没有起伏。支持效果变差时，按当前提示选**调好面罩**或**重接气道回路**，处理后再看一次。 |
| 启动或停止呼吸机 | 装好 M4、给呼吸机通电后，点床边的呼吸机启动。看胸廓运动，接了采样管就一起看呼气波形。机器运行时，底部有**停止呼吸机**。 |
| 手动按压 | 游戏提示符合条件后，在胸部点**开始心肺复苏**。每按一次 **空格键**完成一次游戏里的按压。鼠标仍可操作其他控件。**停止按压**固定在底部，打开除颤器也能用。 |
| 胸外按压机 | 在胸部点**按压机**，再点**安装按压机支架**。装好后点**启动按压机**，留意电量和机器是否在动。AED 分析时按压机可能短暂停下。符合条件时，它可以在放电期间继续运转。底部的**停止按压**也能停机器。 |
| 贴上胸部电极片 | 点床边的除颤器，或在病人胸部选**贴上胸部电极片**。把电极片拖入相同编号的轮廓，也可以先点电极片再点轮廓。每贴好一片就会接上一根线。两片都贴好后再用除颤器面板。 |
| AED 分析、充电和放电 | 打开 AED，点**分析心律**并读机器的提示。机器建议放电且控件可用时，先**充电**，等就绪，再**放电**。如提示手动按压挡住了步骤，先在底部停下。之后复查脉搏和支持情况。 |
| 手动除颤和同步 | 在手动除颤器面板选能量档、充电，留意就绪状态。病历和监护波形支持同步时才选**开启同步**，需要切换时选**关闭同步**。看到**确认电击风险**，先重新确认心律和脉搏。强行电击可能让模拟病人情况变差。 |
| 开始输液 | 点床边的输液泵，选可用的前臂。需要通电的泵、兼容监护仪、适用的补液包和病历要求的血压证据。输液过程中可以看读数的变化。 |
| 已筛查血液、蓝血 | 点床边的输血台，选可用的前臂。确认选中的血袋和价格。读数好转后，仍可能需要处理伤处或其他病因。 |
| 开始恢复血流 | 在有此操作的四级病历中，点胸部查看当前十二导联和前置治疗。设备通电就绪后再确认。保留心电连接，开始观察后继续留意心律和循环。 |
| 保暖、降温、休息 | 检查结果支持时，可在**支持**里保暖或降温。平稳的病历也可能在床边提供**休息后复查**、**让病人喝水休息**、**坐直休息**、**安静休息**或**扶上诊察床休息**。相关读数会逐渐变化，过一会儿再复查。 |
