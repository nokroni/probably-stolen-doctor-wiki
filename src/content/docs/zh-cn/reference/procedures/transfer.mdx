## 查明病因和准备转运

| 操作 | 病历需要什么 |
| --- | --- |
| 断开电源线、隔离植入体端口 | 根据当前病历的提示，在床边用可见的隔离按钮，也可以去**病灶与转运**里找。等游戏标记隔离成功后，再继续稳定病人和复查。 |
| 核对暴露标签、读取剂量牌、查看容器 | 打开病历指出的物件。有些病历还提供**封存暴露物品**。把看见的记录和症状、证人讲述对照起来，再决定如何处理。 |
| 问送诊人、登记物品 | 到病例的**病史**页或仪器的**检查**页问清经过。在**病灶与转运**里选与所见证据吻合的工牌、物品或接触记录。有「无法确认」的选项时，可以如实填。 |
| 检测龙头水样 | 库存需要有一张没用过的水质试纸。用床边按钮完成检测后，游戏会把结果归档给接应人员。 |
| 查阅转诊记录、请医疗舱复核影像 | 病历有**转诊记录**时，可以点开查看病人来店前的读数和心电，再和本次检查对照。部分病历也可以请医疗舱复核影像。需要交接时，另点交接按钮。 |
| 对照发现、填报告 | 有附带的报告要求时，先收集患处发现和证人陈述，再对照要求的读数。提交前看清哪份记录或签字副本会随病人转出。 |
| 选择转运方式、移上留观床 | 看病历是否提供有监护的接应、获批接驳车，或要求留在本诊所。病人能商量费用时，可以单独确认由谁付钱。需要换床时，先完成相应的监护和转运检查，换过来后再按提示检查、测压和看呼吸。 |
| 演练、预约或取消出诊 | 四级诊所空床时，点顶部的出诊名称可以换下一项。有**模拟出诊**的项目要先演练，再按条件预约。开通[夜间病房转诊](../../systems/referrals/)后，切到**病房转诊**并点**预约出诊**，调度会按诊所的器材和库存选一例。要改安排，回到已预约的项目点**取消预约**。 |

两种转运方式都能选时，先看路上需不需要监护。接驳车没有监护仪。病人又有新症状时，复查后再看原来的转运安排还能不能用。
