## 查明病因和准备转运

| 操作 | 病历需要什么 |
| --- | --- |
| 断开电源线、隔离植入体端口 | 根据当前病历的提示，在床边用可见的隔离按钮，也可以去**病灶与转运**里找。等游戏标记隔离成功后，再继续稳定病人和复查。 |
| 核对暴露标签、读取剂量牌、查看容器 | 打开病历指出的物件。有些病历还提供**封存暴露物品**。把看见的记录和症状、证人讲述对照起来，再决定如何处理。 |
| 问送诊人、登记物品 | 到人体图上方或**检查**页问清经过。在**病灶与转运**里选与所见证据吻合的工牌、物品或接触记录。有「无法确认」的选项时，可以如实填。 |
| 检测龙头水样 | 库存需要有一张没用过的水质试纸。用床边按钮完成检测后，游戏会把结果归档给接应人员。 |
| 查阅转诊记录、请医疗舱复核影像 | 打开转诊记录查看之前的读数和心电。合适的病历可以请医疗舱复核影像，用来补充判断依据。正式交接仍要单独操作。 |
| 对照发现、填报告 | 有附带的报告要求时，先收集患处发现和证人陈述，再对照要求的读数。提交前看清哪份记录或签字副本会随病人转出。 |
| 选择转运方式、移上留观床 | 看病历是否提供有监护的接应、获批接驳车，或要求留在本诊所。病人能商量费用时，可以单独确认由谁付钱。需要换床时，先完成相应的监护和转运检查，换过来后再按提示检查、测压和看呼吸。 |
| 演练、预约或取消出诊 | 四级诊所空床时，点顶部的出诊名称可以换下一项。先看设备和库存条件。有演练要求的出诊先完成演练，符合条件后再预约。需要改安排时，用已经预约的项目旁边的取消按钮。 |

## 留观、结案和复诊

- **办理离诊。** 做完要求的治疗、诊断、留观和复查，等按钮变绿。轻伤轻症不必为了凑读数而做病历没有要求的测量。
- **呼叫医疗舱、转交医疗舱。** 当本诊所需要接应而病历允许转运时，提前呼叫。等接应期间继续支持和复查。按当前病历完成交接，或在开放时选**请转运队接手抢救**。需要留在店内完成的病历则继续处理到观察结束。
- **看治疗后有没有变化。** 病情恶化或出现新的症状会打断观察。先处理原因，复查相关发现，再从稳定时开始观察。如果只有读数掉了，先看病人，也看探头或线路。
- **完成专科和术后检查。** 病区面板开放后，按要求申请和归档记录，对照标记的两次观察，再完成可用的演练。手术开始后，换床时重新看脉搏、探头和呼吸。**确认转运检查**、**签收复查结果**和**签署观察完成记录**会核对旁边写的条件。袖带读数过时就再量。可用时，**中止手术**会先要求确认。
- **关闭咨询或结束接诊。** 需要时确认暂缓咨询，查看收据，回窗口听答复。看清病历的转归，再接下一位。
- **打开病例复盘或近期病例。** 可以筛选时间线，打开已保存的检查结果，对照心电和治疗发生的时间。获准时可以查看**病区签署的回执**。病人回来复诊时，先问变化，再做病历要求的检查或安排下一步。
