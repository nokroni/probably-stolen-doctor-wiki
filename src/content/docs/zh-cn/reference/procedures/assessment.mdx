| 想做什么 | 去哪里找，接下来做什么 |
| --- | --- |
| 询问症状 | 在窗口或人体图上方找对话选项。根据病历，可以问什么时候开始不舒服、哪里疼、有没有咳嗽、接触过什么、有没有头晕。复诊时也可能需要问先前做过什么处理，或复查指定的部位。 |
| 接诊 | 先看来诊记录、设备和耗材是否齐全，以及谁付费、预算多少。正式病人在窗口接诊，练习病历直接点**接诊**。接诊后开始计时。 |
| 全身检查、检查结果 | 点底部的**全身检查**。约 2.5 个游戏秒后，点**检查结果**看本次记录，或选中人体图上的部位单独看。情况有变就再查一次。监护读数、检验和证人陈述还要分别取得。 |
| 查看患处、打开遮盖物、看治疗卡 | 按提示选中对应部位。有些病历可以解开外套、查看靴子下面，或读床边的治疗卡。伤处露出来后，再按提示复查。 |
| 检查脉搏、检查血运 | 点能用的一只手或前臂检查脉搏。有些伤病还会在伤处远端的手或脚上提供**检查血运**。心电有波形和手上能摸到脉搏是两回事。 |
| 记录诊断 | 在监护仪下方选择或修改初步诊断，结合来诊记录、检查和读数判断。许多病历会在离诊或交接前核对诊断。急救操作可以先做。 |
