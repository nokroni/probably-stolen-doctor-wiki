---
title: 神经系统症状
description: 通过起病经过、言语、肢体表现和血糖辨别头痛、晕厥与局灶异常。
---

先问病人上一次和平常一样是什么时候。查说话、笑容、抬手和握力。**全身检查**会标记检查的实际时间。符合提示时选完好的手测指尖血糖。纠正后既要重测血糖，也要复查原来的动作异常。

| 诊断 | 游戏里的线索和下一步 |
| --- | --- |
| 反复头痛 | 逐渐加重、和以往相似，言语和动作依旧正常。还在收集线索时可先记为**头痛待查**。病历允许时让病人安静休息，离院前复查头痛、言语和双臂。 |
| 突发剧烈头痛或疑似颅内出血 | 即使首次言语和抬臂看起来正常，也要记下头痛几乎一开始就到了最重。新出现手臂下沉、笑容不对称或越来越嗜睡时，更要尽快按提示支持并**呼叫医疗舱**。 |
| 低血糖 | 出汗、面色苍白、手抖、没力气、反应慢或说话不清。先测血糖，有入口时确认使用**补糖包（GlucoRescue）**，等读数变化后复查原来的异常。 |
| 疑似脑卒中 | 比较两侧。复测血糖已正常时，仍可能有一侧无力或言语改变。交接时带上最后一次表现正常的时间和复查结果。店里缺少所需耗材且开放**无法测血糖，转诊**时，可由医疗舱接手检查。 |
| 短暂晕厥 | 问倒下以前发生了什么，当时有人做了什么。按提示查跌伤、脉搏和血糖，休息后再对照查体。 |
| 药物反应 | 呼吸浅或反应慢也可能像神经系统异常。先查体，核对接触证据，详见[代谢与暴露](../metabolic-exposure/)。 |

## 蓝血和影像评估

三级起，部分游戏中的缺血性卒中病例在检查言语与动作、实测血糖合适后，会开放**蓝血**。**请医疗舱复核影像**可补充起病情况和疑似出血的判断。复查言语与抬臂，把仍存在的异常也一并报告。
