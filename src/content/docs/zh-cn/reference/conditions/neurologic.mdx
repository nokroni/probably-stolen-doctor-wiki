---
title: 神经系统症状
description: 通过起病经过、言语、肢体表现和血糖辨别头痛、晕厥与局灶异常。
---

先问病人上一次和平常一样是什么时候。查说话、笑容、抬手和握力。**全身检查**会标记检查的实际时间。符合提示时选完好的手测指尖血糖。纠正后既要重测血糖，也要复查原来的动作异常。

| 诊断 | 游戏里的线索和下一步 |
| --- | --- |
| 反复头痛 | 逐渐加重、和以往相似，言语和动作依旧正常。病历允许时让病人安静休息，离院前复查头痛、言语和双臂。 |
| 突发剧烈头痛或疑似颅内出血 | 一开始就最疼，新出现的手臂下坠、嘴角不对称或越来越难叫醒，都会改变去向。记录起病和查体，按需支持并呼叫医疗舱。 |
| 低血糖 | 出汗、面色苍白、手抖、没力气、反应慢或说话不清。先测血糖，有入口时确认使用**补糖包（GlucoRescue）**，等读数变化后复查原来的异常。 |
| 疑似脑卒中 | 血糖正常或纠正后仍有一侧无力或言语改变。问清起病，记录查到的表现。店里缺少所需检查时，按病历提供的交接途径处理。 |
| 短暂晕厥 | 问倒下以前发生了什么，当时有人做了什么。按提示查跌伤、脉搏和血糖，休息后再对照查体。 |
| 药物反应 | 呼吸浅或反应慢也可能像神经系统异常。先查体，核对接触证据，详见[代谢与暴露](../metabolic-exposure/)。 |

## 蓝血和影像评估

三级起，部分游戏中的缺血性卒中病例在检查言语与动作、实测血糖合适后，会开放**蓝血**。以按钮提示为准。医疗舱影像评估可补充判断，是独立于用药和交接的操作。复查言语与抬臂，把仍存在的异常也一并报告。
