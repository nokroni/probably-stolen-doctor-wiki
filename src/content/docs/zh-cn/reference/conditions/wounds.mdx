title: 伤口和肢体损伤

---

先做**全身检查**。点击受伤部位，读清伤具体在哪儿，有没有还被衣物盖住。病人的右侧在屏幕左边。一次操作只处理选中的部位。

| 发现 | 游戏内操作和复查 |
| --- | --- |
| **外伤伤口** | 切伤、擦伤或能接触到的浅表穿刺伤都可能出血。按提示先按压止血，再选**包扎**，沿圆形指引缠好。看到提示后松开鼠标，回到原处复查。 |
| 浅表碎屑或松动的碎片 | 病历允许时，把操作窗里的碎片移到托盘。然后复查并包扎。 |
| 接触热源的烧伤 | 选择病历显示的烧伤敷盖，用合适的敷料或鱼皮。过了几天出现肿热、渗液时，按[伤口感染](../infection/)再查。 |
| 手腕扭伤、肩部拉伤或胸壁拉伤 | 问清怎么受伤的，查有无变形。按提示检查活动或远端循环，病历允许时休息后复查。 |
| 骨折 | 打开**夹板固定**，顺着窗口指引摆好两段骨块和夹板。需要时复查远端循环。多处受伤要逐处操作。 |
| 关节脱位 | 打开关节复位，把图示关节移到轮廓内，位置对了再松开。结束前复查远端。 |
| **伤口复查** | 读上一次的记录，问病人有什么变化，再查同一位置后结束随访。 |

局部处置、诊断和所需留观都完成后按病历安排离院。新出现的肿胀、脉搏变弱或血压继续掉，可能需要进一步处理。另见[重度外伤](../major-trauma/)与[伤口操作](../../procedures/wound-care/)。
