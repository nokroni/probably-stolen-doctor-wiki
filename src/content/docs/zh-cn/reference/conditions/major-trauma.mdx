---
title: 重度外伤
description: 区分体表大出血、深部损伤、胸部外伤和肢体离断。
---

完成**全身检查**后逐处查看。如果伤口被衣物遮住，就按提示掀开。敷料看着干，或者指夹血氧数字还行，循环也可能已经变差。胸部挨了重击，还要对照心电、实际脉搏和新测的血压。

| 诊断 | 游戏内检查和处理 |
| --- | --- |
| 体表大出血 | 暴露伤处，按提示按压止血，再逐处包扎。复查脉搏和血压。病历允许且装有输血设备时，按提示输血。 |
| 钝性内伤或腹部穿透伤 | 查体并扫查来源，病历有固定入口时先稳住嵌入的异物，必要时支持循环。器材、耗材齐全且允许就地修复时，捕获和封合是两步。完成后复查血压和残余出血，确认是否还需转运。 |
| **胸壁损伤** | 胸口受撞后，对照局部压痛和两侧胸廓起伏。扫查发现胸腔积气或积血时，按结果更新初步诊断。 |
| 气胸 | 胸部受伤后，一侧胸廓起伏较小。该侧超声可能显示肺滑动消失、未见积液。三级起，适用病例具备当前血压和无菌包等条件时会开放胸腔引流。照游戏操作窗完成，再查胸廓和血压。 |
| 血胸 | 扫查可能显示膈肌上方或患侧肺底积液。引流可以改善呼吸，但失血仍需处理。按病历提示做止血、输血或修复，再测血压。 |
| 胸伤合并肢体出血 | 扫查胸部，另行处理看得见的伤口。病历允许时可先记录初步诊断，等结果出来，再选择与受伤部位和扫查结果相符的合并诊断。 |
| **外伤性肢体离断** | 从床上的病人身上能看到缺失的部位。包扎残端，分别处理其他伤处，把袖带、脉搏检查和通路移到能用的一侧。病历需要时确认离断组织的交接。 |
| 手指离断 | 在手部图上确认是哪只手、哪根手指。检查组织盒，确认病人同意。器材和床旁条件满足时按提示再植，随后复查指端血流。需要转运时先包扎，再连同已登记的组织盒交接。 |

要输血时，先确认托盘选中的血制品。**血袋**和**蓝血**用途不同，费用按耗材报价显示。已预留的袋子被移走后，重新选一袋可用的。处置后再复查循环。
