---
title: 重度外伤
description: 区分体表大出血、深部损伤、胸部外伤和肢体离断。
---

逐处检查。敷料看着干，或者指夹血氧数字还行，循环也可能已经变差。留意脉搏弱、血压掉、手脚冷、腹部变化或胸廓起伏不对称。

| 诊断 | 游戏内检查和处理 |
| --- | --- |
| 体表大出血 | 暴露伤处，开放时按压止血，再逐处包扎。复查脉搏和血压。病历允许且装有输血设备时，按提示补充血液支持。 |
| 钝性内伤或腹部穿透伤 | 查体并扫查来源，病历有固定入口时先稳住嵌入的异物，必要时支持循环。器材、耗材齐全且允许就地修复时，捕获和封合是两步。完成后复查血压和残余出血，确认是否还需转运。 |
| 气胸 | 胸部受伤后，一侧胸廓起伏较小。用胸部超声区分胸腔积气与积血。三级起，适用病例具备合格血压读数和无菌包等条件时，会开放胸腔引流。照操作窗的图示完成，再看胸廓和血压。 |
| 血胸 | 影像显示胸腔积血。引流可以改善呼吸，但失血仍需处理。按提示做止血、输血或修复，再测血压。 |
| 胸伤合并肢体出血 | 扫查受影响的胸部，另行处理看得见的伤口。不同人的描述对不上时，按实际查到的线索填写记录。 |
| 肢体离断 | 人体图上会缺少受伤部分。包扎残端，分别处理其他伤处，把袖带、脉搏检查和通路移到能用的一侧。病历需要时确认离断组织的交接。 |
| 手指离断 | 查游戏中的组织盒并确认同意。器材和床旁要求都满足时，才使用开放的再植操作。随后复查指端血流，或包扎后带记录的组织盒交接。 |
