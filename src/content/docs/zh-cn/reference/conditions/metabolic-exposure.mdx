先读病人和目击者怎么说，查看带来的东西。如果还有危险源且界面给出了隔离按钮，先处理危险源。来源或物主没查准，就在病历里保留不确定。

| 发现或诊断 | 游戏里怎么查和处理 |
| --- | --- |
| 热损伤或低温暴露 | 测体温。皮肤很热、反应混乱，要考虑热损伤。衣服湿冷、发抖或回答变慢，要考虑低温。按提示降温或复温，等体温有变化再测。 |
| 电解质紊乱或错过净化治疗 | 病人抽筋、心跳漏拍或突然倒下时，先读病史，再做**床旁生化**。看到净化治疗卡就到左前臂查看。因错过净化治疗而骤停的病例，可以边按压边从左前臂做生化，结果符合时按提示用**补液包**。 |
| 电击伤 | 先按提示切断电源。查呼吸、手腕脉搏和能测到的心电、血压。按游戏开放的操作处理心律和循环。 |
| 辐射暴露 | 核对徽章和目击记录，对上随身物品，用病历提供的隔离或封存操作。检查是否还有撞伤或内伤。需要交接时把发现一并告诉医疗舱。 |
| 原版药品或其他物质暴露 | 查包装、药瓶、食物容器和目击者描述，把经过和呼吸、脉搏、血糖对照。如果呼吸一直差，或病历要求交接，就保持支持并安排转运。 |
| 物质依赖 | 有监护条件的面诊中，先问诊和查体，再讨论恢复计划。病人同意、病历允许时使用**赛纳普斯注射器**，按提示复查并安排后续。 |

## 把标签和查体对上

- **奥克西莫及混杂证据。** 有两个包装时，问清实际用了哪个，再查随身物品记录。只有病历确认适用暴露后才用**纳洛通**。给药后复查呼吸。
- **梦尘、芬太片、梦魇尘、梦魇帽菇和山奈德片。** 撕开的包装、昏昏欲睡、突然惊醒的动作或吃过什么，都是问诊线索。保持呼吸支持，按病历把相应物品或记录交给接手的人。奥克西莫的用药入口需要相应的确认证据。
- **咖啡因药片或零嚼。** 问近期吃了什么，上一餐又是什么时候，再测血糖。测到偏低就按提示处理，随后复查最初的症状。
