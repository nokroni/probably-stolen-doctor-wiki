title: 代谢与暴露
description: 查询电解质、温度、药物、电击和辐射相关线索。
---

先读病人和目击者怎么说，查看带来的东西。如果还有危险源且界面给出了隔离按钮，先处理危险源。来源或物主没查准，就在病历里保留不确定。

| 发现或诊断 | 游戏里怎么查和处理 |
| --- | --- |
| 热损伤或低温暴露 | 测体温。皮肤很热、反应混乱，要考虑热损伤。衣服湿冷、发抖或回答变慢，要考虑低温。按提示降温或复温，等体温有变化再测。 |
| 电解质紊乱或错过净化治疗 | 病人抽筋、心跳漏拍或突然倒下时，先读病史，再做**床旁生化**。有净化治疗卡时，到病历标出的部位查看。部分病例允许在按压期间做生化，结果符合时可用**补液包**纠正电解质。处置后复查心律和脉搏。 |
| 肾脏或肝脏指标升高 | 电解质正常时，床旁生化也可能提示肾脏或肝脏指标升高。两部分结果都要看，再结合受影响的部位、症状和当前循环选处置。电解质正常仍可能有内伤。 |
| 电击伤 | 提示破损的电源线还带电时，先点床旁左下方的**断开电源线**。再查胸廓起伏和手腕脉搏，按条件接心电、测血压。发现心律或循环异常时，按床旁提示处理。 |
| 辐射暴露 | 按病历提示**读取剂量牌**、问目击者，并隔离或封存相应物品。剂量牌没来得及读、屏幕损坏，或只查到警报时，剂量都还无法确认。检查有无撞伤或内伤。即使暴露情况待查，病历也可能允许在稳定病人后交接。把查到的情况和还没查清的地方一起交给医疗舱。 |
| 原版药品或其他物质暴露 | 查包装、药瓶、食物容器和目击者描述，把经过和呼吸、脉搏、血糖对照。如果呼吸一直差，或病历要求交接，就保持支持并安排转运。 |
| 物质依赖 | 有监护条件的面诊中，先问诊和查体，再讨论恢复计划。病人同意、病历允许时使用**赛纳普斯注射器**，按提示复查并安排后续。 |

## 把标签和查体对上

- **暴露合并胸部外伤。** 如果病历提供呼吸支持，留意胸廓和血氧的变化，并重新用袖带测压。血氧回升时，血压仍可能下降。
- **奥克西莫及混杂证据。** 有两个包装时，问清实际用了哪个，再查随身物品记录。只有病历确认适用暴露后才用**纳洛通**。给药后复查呼吸。
- **梦尘、芬太片、梦魇尘、梦魇帽菇和山奈德片。** 撕开的包装、昏昏欲睡、突然惊醒的动作或吃过什么，都是问诊线索。保持呼吸支持，按病历把相应物品或记录交给接手的人。奥克西莫的用药入口需要相应的确认证据。
- **咖啡因药片或零嚼。** 问近期吃了什么，上一餐又是什么时候，再测血糖。测到偏低就按提示处理，随后复查最初的症状。
