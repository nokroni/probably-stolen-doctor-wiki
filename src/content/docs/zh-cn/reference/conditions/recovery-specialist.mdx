---
title: 恢复观察与专科处理
description: 查转床后的复测、整形面诊、专科设备和离院后的记录。
---

转到恢复床或换了支持设备以后，病历可能出现新发现。先看上次读数是什么时间的。用病人现在的查体和仪器结果决定能不能签字或交接。

| 情况 | 游戏里怎么做 |
| --- | --- |
| 转床后探头故障 | 先摸脉、看胸廓起伏。重新夹好提示所指的探头。旧血压早于搬动或已过期，就再测一次。 |
| 搬动或接线后呼吸变差 | 看实际胸廓起伏，需要时重新接管或调整面罩，按病历支持呼吸。继续看新的血压与监护读数。 |
| 已愈合的瘢痕面诊 | 检查患处、确认同意。有标记入口时打开瘢痕轮廓窗口。确认双方同意的轮廓、延期，或按执照提供的入口做表面修整，再完成所需观察。 |
| 植入体或全身性问题的专科处置 | 检查相关连接、现有查体和专科设备。部分流程要分开完成干预、转床和签署观察。每一步都看病人、设备和当前读数。 |
| 局部处置后随访 | 先读之前的发现，问哪里有变化，再做指定的复查，把新结果和旧记录对照起来。 |
| 结案后复盘 | 打开**病例复盘**，在时间线上找恶化、操作、复测和曾中断的留观。也可以从最近病例打开原记录。 |

<details data-pagefind-ignore>
  <summary>展开查看剧情病名</summary>
  <p>哨兵病（Sentinel Collapse）。按当前病历提供呼吸和循环支持，符合线索时可用已验真的专科药品。开放专科处置后使用装好的四级设备，确认气道和手腕脉搏，依提示完成校准。恢复期复查呼吸并重新测血压。签署前读数过期就再测。</p>
</details>
