转到恢复床或换了支持设备以后，病历可能出现新发现。先看上次读数是什么时间的。用病人现在的查体和仪器结果决定能不能签字或交接。

| 情况 | 游戏里怎么做 |
| --- | --- |
| 转床后探头故障 | 先摸脉、看胸廓起伏。重新夹好提示所指的探头。旧血压早于搬动或已过期，就再测一次。 |
| 搬动或接线后呼吸变差 | 看实际胸廓起伏，需要时重新接管或调整面罩，按病历支持呼吸。继续看新的血压与监护读数。 |
| 已愈合的瘢痕面诊 | 检查患处、确认同意。有标记入口时打开瘢痕轮廓窗口。确认双方同意的轮廓、延期，或按执照提供的入口做表面修整，再完成所需观察。 |
| 局部处置后随访 | 先读之前的发现，问哪里有变化，再做指定的复查，把新结果和旧记录对照起来。 |
| 结案后复盘 | 打开**病例复盘**，在时间线上找恶化、操作、复测和曾中断的留观。也可以从最近病例打开原记录。 |

## 植入体异常

先检查受影响的部位。病历提供检查植入体接口的操作时，按提示检查，再根据发现决定要复测哪些读数、提供哪些支持。

| 发现 | 游戏内检查和处理 |
| --- | --- |
| 植入体边缘发热、敷料有异味或伤口渗液 | 检查局部和体温。按提示抗感染，病情变差时复查呼吸和血压。见[发热与感染](../infection/)。 |
| 移植物接缝表面干燥，但附近肿胀或有深部压痛 | 按提示扫查患处，对照脉搏和血压。病历可能要求输血、修复或带监护转运。见[重度外伤](../major-trauma/)。 |
| 植入体接口异常，伴心跳加快 | 对照心电、手腕脉搏和当前血压。根据读到的心律使用设备开放的操作。见[心律与心脏骤停](../rhythms/)。 |
| 气道植入管有哨声，或胸廓起伏减弱 | 检查胸廓和呼吸回路。按提示重接回路或支持呼吸，再看胸廓起伏和新的读数。见[呼吸问题](../breathing/)。 |

## 专科治疗

遇到需要专科治疗的病症，先读床旁病历，核对维持用药、设备和耗材。若病历提供植入操作，依照当前病历备齐器材，术后按要求复测。签署前查看最新的监护和观察记录。相关器材见[免疫调节模块](../../items/immune-regulator/)。
