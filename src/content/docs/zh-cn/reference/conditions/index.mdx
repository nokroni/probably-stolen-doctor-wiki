title: 疾病与症状
description: 按症状查找医生模组中的疾病、检查和处理入口。
---

手里只有主诉或一道监护读数时，先看[症状与首轮检查](./symptoms/)。要比较诊断、找治疗入口，再打开下面的专题。

这里收录的是**医生模组 0.17.40** 的游戏内容。复测、留观、离院或交接，看床旁病历当前的提示。

| 专题 | 可以查到什么 |
| --- | --- |
| [胸痛](./chest-pain/) | 胃食管反流、胸壁痛、急性冠脉综合征、心肌梗死、疑似肺栓塞 |
| [心律与心脏骤停](./rhythms/) | 心律过快或过慢、室颤、室速、室上速、房颤、心脏停搏、无脉电活动和再次恶化 |
| [呼吸问题](./breathing/) | 哮喘、过敏、吸入性损伤、呼吸支持及设备故障 |
| [发热与感染](./infection/) | 伤口或植入体感染、肺炎、肾盂肾炎、全身性感染时的循环问题 |
| [神经系统症状](./neurologic/) | 头痛、短暂晕厥、言语或动作异常、低血糖与脑卒中 |
| [腹痛](./abdominal/) | 胃部不适、胃肠炎、脱水、疑似阑尾炎 |
| [代谢与暴露](./metabolic-exposure/) | 体温、电解质、辐射、电源危险、药物或其他物质反应 |
| [伤口和肢体损伤](./wounds/) | 切割伤、烧伤、碎屑、扭伤、脱位和骨折 |
| [重度外伤](./major-trauma/) | 大出血、穿透伤、气胸与血胸、手指或肢体离断 |
| [恢复观察与专科处理](./recovery-specialist/) | 转床后复测、瘢痕评估、专科设备和随访 |

记录初步诊断前，先问清什么时候开始，或查一查不舒服的部位。警报暂时消失、心电看着规整，或者一次血压读数，都需要结合病人当下的情况。操作入口和耗材见[床旁操作](../procedures/)与[物品和设备](../items/)。
