心电波形看着有规律，手腕也可能摸不到脉。把脉搏、可读的心电和当前可测的血压对照。导联或探头掉了，先单独检查连接。

| 查到什么 | 游戏内处理 |
| --- | --- |
| **缓慢心律失常**，伴有头晕或低血压 | 看心电，复测可用的血压。查体后测到低血压，合适的病例会开放**循环支持包（PulseLift）**。继续查冠脉、低温或代谢方面的原因。 |
| **快速心律失常**，还能摸到脉搏 | 对照症状和血压，区分规整的室上速和不齐的房颤。有同步标记且病历允许时，可以用 **SYNC**。稳定的房颤可能只需监护与交接。 |
| 室性心动过速（VT）或室颤（VF） | 游戏里可见规整的宽波、形状不断变化的宽波，或完全紊乱的活动。先查脉搏，在胸部贴好电极片，看 AED 建议或手动设备提示。游戏内室速和室颤使用非同步电击。 |
| 心脏停搏，或心电有活动却摸不到脉 | 按提示支持通气和做心肺复苏。手动按压每按一次空格算一下。恢复过程中可能先出现缓慢的逸搏心律。查明病因，确认脉搏恢复后再进入观察。 |
| 电击后循环依旧微弱或摸不到脉 | 继续所需的支持，复测脉搏和血压，查失血、心肌损伤等原因。四级符合条件的病例会开放**肾上腺素**。 |
| 室速或室颤反复出现 | 补记新的心律和血压，检查上次稳定后发生了什么，包括冠脉处置。已有复发记录、脉搏、近期血压和可读心电时，合适病例可用**稳律缓冲剂**延缓再次恶化。 |

## 结束前复测

按提示更新诊断和读数。出现新症状或再次恶化时，本次留观中断。先处理变化，再完成重新开始的观察，之后才能离院或交接。
