这里介绍的是模组里的模拟操作。哪些按钮能用，要看病历记录、执照等级、装好的设备、电量和库存。碰到灰色按钮时，先看它的提示，或者瞄一眼左下角的「我」，找出这份病历还缺哪一步。

## 接诊和初查

| 想做什么 | 去哪里找，接下来做什么 |
| --- | --- |
| 询问症状 | 在窗口或人体图上方找对话选项。根据病历，可以问什么时候开始不舒服、哪里疼、有没有咳嗽、接触过什么、有没有头晕。复诊时也可能需要问先前做过什么处理，或复查指定的部位。 |
| 接诊 | 先看来诊记录、设备和耗材是否齐全，以及谁付费、预算多少。正式病人在窗口接诊，练习病历直接点**接诊**。接诊后开始计时。 |
| 全身检查、检查结果 | 点底部的**全身检查**。约 2.5 个游戏秒后，点**检查结果**看本次记录，或选中人体图上的部位单独看。情况有变就再查一次。监护读数、检验和证人陈述还要分别取得。 |
| 查看患处、打开遮盖物、看治疗卡 | 按提示选中对应部位。有些病历可以解开外套、查看靴子下面，或读床边的治疗卡。伤处露出来后，再按提示复查。 |
| 检查脉搏、检查血运 | 点能用的一只手或前臂检查脉搏。有些伤病还会在伤处远端的手或脚上提供**检查血运**。心电有波形和手上能摸到脉搏是两回事。 |
| 记录诊断 | 在监护仪下方选择或修改初步诊断，结合来诊记录、检查和读数判断。许多病历会在离诊或交接前核对诊断。急救操作可以先做。 |

## 监护和诊断仪器

| 操作 | 前置条件和读数 |
| --- | --- |
| 接上心电导联、检查接线 | 用供电正常的监护仪，在胸部接心电导联。已连接但信号差时，选**检查接线**。放电后等波形恢复，再结合新摸到的脉搏判断。 |
| 夹上血氧探头 | 装了指夹且监护仪有电时，选择一只可用的手。等脉搏波和血氧读数稳定。提示指夹松动时，在手部或**支持**里点**重新夹好指夹**，再对照手腕脉搏和呼吸情况。 |
| 打开血压袖带、绑上袖带、测血压 | 选可用的上臂，在袖带面板先绑好再启动。袖带开始测量后可以先处理其他问题。治疗或换床后，有些病历会要求再测一次。M4 还提供**自动测压**和**停止循环测压**。 |
| 量体温、接上体温探头 | 在头部打开体温计。手持体温计给出一次读数。装好体温监测设备并给 M4 供电后，可以接探头连续观察。底部的**拔下探头**可停止监测。 |
| 测血糖 | 装好血糖采样器，选可用的手或到**检查**里测量。等结果出来后再决定下一步。补糖后复测，如果握力或说话还有变化，把两次结果对照起来看。 |
| 采集十二导联、查看十二导联 | 在胸部或**床旁仪器 → 检查**操作。需要装好十二导联记录仪和通电的 M3 或 M4，接上心电并保持信号。采集后打开报告，看结果和采集时间。 |
| 保存心电 | M3 或 M4 接上导联、波形清楚时，可以保存当前心电。处理后或者异常复发时，把前后的心电对照起来看。十二导联报告另行保存。 |
| 接动脉管并调零 | 装好动脉压传感器并给兼容监护仪供电。在前臂或**检查**里操作，等调零完成。动脉压实时波形起来后，可和最近的袖带读数、病人的情况一起看。 |
| 采集超声 | 在**检查**页选胸部、腹部或可检查的肢体，用有电的超声仪采集。报告会标出区域。病历要求看指定部位时，要选对地方。 |
| 生化检验 | 在前臂或**检查**页使用有电的床旁检验仪。按窗口的图示取样，再把样本放进分析槽。看完结果，再决定是否需要纠正异常。 |
| 接上、接回或拔下 CO₂ 采样管 | 装好呼吸机和通电的 M4 后，在**床旁仪器 → 支持**里接管。辅助通气时，等完整的一次呼吸采样，再结合胸廓起伏看波形。拔管后该通道清空。 |
| 归档读数、标记血压情况 | M4 和抢救站控制器有电时，**归档读数**会保存当时的监护结果。如果病历提供**血压平稳**或**标记低血压**，先取得要求的读数，再按结果选。 |

## 通气、循环和除颤

| 操作 | 去哪里找，接下来做什么 |
| --- | --- |
| 辅助通气、调好面罩 | 装好呼吸囊面罩后，在头部或床边的快捷项启动。看胸口有没有起伏。支持效果变差时，按当前提示选**调好面罩**或**重接气道回路**，处理后再看一次。 |
| 启动或停止呼吸机 | 有 M4 和通电的呼吸机时，在**支持**里启动。看胸廓运动，接了采样管就一起看呼气波形。机器运行时，底部有**停止呼吸机**。 |
| 手动按压 | 游戏提示符合条件后，在胸部点**开始心肺复苏**。每按一次 **空格键**完成一次游戏里的按压。鼠标仍可操作其他控件。**停止按压**固定在底部，打开除颤器也能用。 |
| 胸外按压机 | 在胸部点**按压机**，再点**安装按压机支架**。装好后点**启动按压机**，留意电量和机器是否在动。AED 分析时按压机可能短暂停下。符合条件时，它可以在放电期间继续运转。底部的**停止按压**也能停机器。 |
| 贴上胸部电极片 | 点人体图的胸部，把两片有编号的电极拖到对应轮廓里。等连接完成，再使用除颤器面板。 |
| AED 分析、充电和放电 | 打开 AED，点**分析心律**并读机器的提示。机器建议放电且控件可用时，先**充电**，等就绪，再**放电**。如提示手动按压挡住了步骤，先在底部停下。之后复查脉搏和支持情况。 |
| 手动除颤和同步 | 在手动除颤器面板选能量档、充电，留意就绪状态。病历和监护波形支持同步时才选**开启同步**，需要切换时选**关闭同步**。看到**确认电击风险**，先重新确认心律和脉搏。强行电击可能让模拟病人情况变差。 |
| 开始输液 | 选可用的前臂，在**支持**里操作。需要通电的输液泵、兼容监护仪、适用的补液包和病历要求的血压证据。输液过程中可以看读数的变化。 |
| 已筛查血液、蓝血 | 装好输血台后，选可用的前臂，使用病历开放的输血选项。确认选中的血袋和价格。读数好转后，仍可能需要处理伤处或其他病因。 |
| 开始恢复血流 | 在有此操作的四级病历中，点胸部查看当前十二导联和前置治疗。设备通电就绪后再确认。保留心电连接，开始观察后继续留意心律和循环。 |
| 保暖、降温、休息 | 检查结果支持时，可在**支持**里保暖或降温。平稳的病历也可能在床边提供**休息后复查**、**让病人喝水休息**、**坐直休息**、**安静休息**或**扶上诊察床休息**。相关读数会逐渐变化，过一会儿再复查。 |

## 药品和耗材

床边点**药品**，从适用的前臂打开**注射盘**，或用**床旁仪器 → 治疗托盘**。确认前看清批次、纯度和当前价格。可以用**设置急用操作**给常用药或包扎设快捷项。某些药包还要配一支注射器。没起效的剂量也会扣耗材，决定是否再用之前，先看病人情况和新的起效机会。

| 操作 | 病历会核对什么 |
| --- | --- |
| 广谱抗感染包、补糖包、循环支持包和电解质支持 | 分别看有没有感染证据、测到低血糖、循环需要支持，或生化结果异常。给药后看效果，结案前复查相应的发现。 |
| 纳洛通注射器 | 查阅暴露记录，确认病历支持这个用法。按钮亮起后才可给药。之后复查呼吸，继续观察。 |
| 肝素 | 在需要的病历里，先取得所要求的冠脉相关检查证据，然后到前臂确认给药，再跟进下一项操作。 |
| 升压桥接剂 | 三级药品，适用于病历允许、有脉搏且量到低血压的情况。选前臂给药，在支持期间复查血压和心电。 |
| 稳律缓冲剂 | 四级药品。快捷项会检查脉搏、近期血压、可读的心电和已记录的复发。起效后可以推迟下一次复发。即使波形有好转，也要再量血压。 |
| 肾上腺素 | 四级支持药品。病历需记录摸不到脉搏，或发现严重循环不良且持续。前臂操作可用时再选批次。之后继续所需的支持并复查循环。 |
| 原版止痛和局部感染用药 | **药品**里可能出现需监护的止痛针，或适用的噬菌霉素片。先问清楚、检查患处，并接好要求的探头。给药后留意呼吸和患处。 |
| 原版外用药和诊所生物凝胶 | 在已检查的部位，查看是否可以用药膏、医用酒精、鱼卵、鱼皮敷料或诊所自制生物凝胶。每种都有自己的库存与适用条件。一些病历还会提供资助方的蓝血。 |
| 安抚、商量康复和复诊用药 | 按病历提供的动作安抚病人、**给予舒痛片**或**商量戒断安排**。有些监护复诊会在沟通后开放相应药物。有的病历允许陪护，或在继续支持时请接应人员接手。 |
| 验真的维持用药 | 专科病历提供留存药品时，按可见按钮预订或领取。点**使用验真的免疫维持针**时，游戏会核对具体的可用针剂，然后记录这次用药。 |
| 离诊带药 | 符合条件的离诊可以开舒痛片或噬菌霉素片。先确认价格和库存，再签离诊。 |

## 动手操作

| 操作 | 游戏窗口里要做什么 |
| --- | --- |
| 加压止血 | 选已露出的出血部位。打开操作窗，把画面里的压垫按在引导位置，等提示变化。可以包扎时完成包扎，再看看这一处。 |
| 清理松动碎屑 | 检查浅表伤口后，把窗口里松动的小碎片移到托盘。随后处理压力或敷料。较深或卡在伤处的异物有单独的操作。 |
| 包扎止血、包扎烫伤 | 点患处，用提示可选的绷带、烧伤敷料或**鱼皮敷料**。按住卷沿圈绕，进度条满了再松开鼠标固定。每次完成只处理选中的部位。回人体图看看标记和出血有没有变。 |
| 夹板固定 | 点已确认骨折的位置。把两段图示骨头拖进各自的轮廓，再把方形固定板放到接合处。一次处理一处，病历要求时复查血运。 |
| 关节复位 | 从已检查的部位打开操作窗，把圆形一端拖进对应的轮廓再松手。结束后检查提示的手掌或其他远端部位。 |
| 固定异物 | 在异物所在部位打开操作窗，把两块图示固定垫放进标好的位置。处理完复查伤处，根据病历准备后续诊疗或转运。 |
| 胸腔引流 | 三级以上、病历开放该操作时，选胸部。先完成要求的检查、超声、血压和支持，备一份无菌操作包。按窗口内的导向操作器具，接着推动滑杆。复查胸廓起伏和血压，残余出血可能还要另做处理。 |
| 自动修复、工具准备 | 在有记录的病灶处操作。先完成病历要求的扫描、血压和支持，确认无菌操作包与手术机电量。适用的表面修整可以用外科工具组辅助。等待机器完成，再看处理结果。 |
| 用手术机取出异物并封合 | 在已扫描且符合条件的部位操作，游戏会核对循环、近期血压、输血支持和电量。按窗口引导安装收集盒。异物取出和封合是两步。再测一次血压，根据病历封合伤处或交给转运队。 |
| 显微托架接合断指 | 在患手先**检查组织盒并征求同意**。条件齐备后，用有电的手术机、显微设备和无菌断指接合件。按托架图示操作，再点**检查指尖血流**。如果这份病历需要转运，包扎患手并把记录的组织盒一并交接。 |
| 肢体缺失时的处理 | 残端和其他伤处分别处理。根据提示，把指夹、袖带和接入位置换到仍可用的一侧。包扎后复测血压，交接时看清组织盒是否随病人移交。 |
| 瘢痕修整、标记或暂缓 | 检查患处并**征询患者意愿**。对方同意后再**标出瘢痕轮廓**。如果对方想改范围，按要求重做标记，也可**暂缓修整**。**表面修整**要有已确认的轮廓和病历要求的复查。 |

## 查明病因和准备转运

| 操作 | 病历需要什么 |
| --- | --- |
| 断开电源线、隔离植入体端口 | 根据当前病历的提示，在床边用可见的隔离按钮，也可以去**病灶与转运**里找。等游戏标记隔离成功后，再继续稳定病人和复查。 |
| 核对暴露标签、读取剂量牌、查看容器 | 打开病历指出的物件。有些病历还提供**封存暴露物品**。把看见的记录和症状、证人讲述对照起来，再决定如何处理。 |
| 问送诊人、登记物品 | 到人体图上方或**检查**页问清经过。在**病灶与转运**里选与所见证据吻合的工牌、物品或接触记录。有「无法确认」的选项时，可以如实填。 |
| 检测龙头水样 | 库存需要有一张没用过的水质试纸。用床边按钮完成检测后，游戏会把结果归档给接应人员。 |
| 查阅转诊记录、请医疗舱复核影像 | 打开转诊记录查看之前的读数和心电。合适的病历可以请医疗舱复核影像，用来补充判断依据。正式交接仍要单独操作。 |
| 对照发现、填报告 | 有附带的报告要求时，先收集患处发现和证人陈述，再对照要求的读数。提交前看清哪份记录或签字副本会随病人转出。 |
| 选择转运方式、移上留观床 | 看病历是否提供有监护的接应、获批接驳车，或要求留在本诊所。病人能商量费用时，可以单独确认由谁付钱。需要换床时，先完成相应的监护和转运检查，换过来后再按提示检查、测压和看呼吸。 |
| 演练、预约或取消出诊 | 四级诊所空床时，点顶部的出诊名称可以换下一项。先看设备和库存条件。有演练要求的出诊先完成演练，符合条件后再预约。需要改安排时，用已经预约的项目旁边的取消按钮。 |

## 留观、结案和复诊

- **办理离诊。** 做完要求的治疗、诊断、留观和复查，等按钮变绿。轻伤轻症不必为了凑读数而做病历没有要求的测量。
- **呼叫医疗舱、转交医疗舱。** 当本诊所需要接应而病历允许转运时，提前呼叫。等接应期间继续支持和复查。按当前病历完成交接，或在开放时选**请转运队接手抢救**。需要留在店内完成的病历则继续处理到观察结束。
- **看治疗后有没有变化。** 病情恶化或出现新的症状会打断观察。先处理原因，复查相关发现，再从稳定时开始观察。如果只有读数掉了，先看病人，也看探头或线路。
- **完成专科和术后检查。** 病区面板开放后，按要求申请和归档记录，对照标记的两次观察，再完成可用的演练。手术开始后，换床时重新看脉搏、探头和呼吸。**确认转运检查**、**签收复查结果**和**签署观察完成记录**会核对旁边写的条件。袖带读数过时就再量。可用时，**中止手术**会先要求确认。
- **关闭咨询或结束接诊。** 需要时确认暂缓咨询，查看收据，回窗口听答复。看清病历的转归，再接下一位。
- **打开病例复盘或近期病例。** 可以筛选时间线，打开已保存的检查结果，对照心电和治疗发生的时间。获准时可以查看**病区签署的回执**。病人回来复诊时，先问变化，再做病历要求的检查或安排下一步。
