名称以医生专精 0.17.40 为准。下文的治疗与配方均为**游戏内机制**。

**怎么买器材？** 一级发放入门器材。从二级起，医疗器材商轮换出售当前执照等级可以买到的设备和耗材。表里标的是通常的购买等级。医疗舱物资箱也可能开出高等级机器，越高级越少见。捡到机器后，还得装上器材架，接好电源和配套设备。

**药放哪儿才拿得到？** 店里未锁住的自有库存都能供床旁取用，包括展示柜、后仓和药品收纳箱。从生产机器取出成品后再给病人用。确认前可以看清具体批次和按当前行情计算的价格。用了但没起效的药也会消耗。

| 物品 | 用途与来源 |
| --- | --- |

| 如何成为一名医生 | 开诊时收到的图解手册，可以收进文件盒。找不到操作时翻一翻。 |

## 监护与检查

| 器材 | 等级 | 用法 |
| --- | --- | --- |
| M2 床旁监护仪 | I | 入门监护仪。接好相应导联和探头后，可以看实时心电、脉搏血氧或测袖带血压。 |
| 指夹探头 | I | 夹在手指上。监护仪有电时可看脉率、SpO₂ 与脉搏波。 |
| 血压袖带 | I | 在上臂绑好袖带再测量，耗电由监护仪承担。病历需要新读数时记得复测。 |
| 水银体温计 | I | 选头部手动测量，需要等几秒才出数。 |
| 血糖仪 | I | 随入门设备发放。装入器材架后，在手指上测血糖。 |
| M3 诊断监护仪 | II | 可以保存短段心电图，供前后对比。 |
| 十二导联心电图机 | II | 接好胸部导联，用有电的 M3 或 M4 录取心电图。报告随病人当时的情况变化。 |
| 动脉压传感器 | II | 接好动脉压线路并归零，可在兼容监护仪上连续看压力。由监护仪供电。 |
| M4 重症监护仪 | III | 支持自动袖带测压。接好配套设备后，可连续显示 ABP、EtCO₂ 等通道。可装原版模组。 |
| 电子体温计 | III | 在头部测量，比水银体温计出数快。 |
| 便携超声仪 | III | 扫查所选部位，寻找表面看不出的异常。需要设备电源或医疗电源总站。 |
| 床旁检验仪 | III | 采样后把样本放进通电的检验仪，当场看结果。 |
| 连续体温监测仪 | IV | 在头部接好探头，有电的 M4 会一直显示体温。 |
| 工作站控制模块 | IV | 搭配 M4，同一工作站可记录和比较两次床旁观察。可装原版模组。 |

## 治疗器材

| 器材 | 等级 | 用法 |
| --- | --- | --- |
| 呼吸囊和面罩 | I | 入门器材。在头部装好面罩，给病人提供呼吸支持。 |
| 便携式 AED | I | 先在胸部贴好两片电极，再到机器上分析心律，按提示放电。入门 AED 附带一块满电的能量电池。 |
| 注射盘 | I | 随入门物资发放，装在床旁器材架上。选可用的前臂取药，核对批次、纯度和所需耗材后再确认。 |
| 手动除颤器 | II | 设定能量，完成充电后通过贴好的胸部电极片放电。有独立供电槽和原版模组槽。 |
| 输液泵 | II | 通过已接好的管路，输注符合条件的补液包。需要设备电源或医疗电源总站。 |
| 转运呼吸机 | III | 接好并供电后持续提供呼吸支持。M4 可显示监测到的 EtCO₂ 波形。 |
| 输血台 | III | 检查并输注符合条件的普通血袋。给输血台供电，在诊所备好密封血袋。 |
| 自动手术机 | III | 用于符合条件的取物、修复或封合操作。每项操作会列出所需的一次性耗材。 |
| 留观床 | III | 为符合条件的术后恢复提供有人员照看的留观位置。 |
| 胸外按压机 | III | 装在胸部后可以持续按压。游戏中放电时也能继续运行，注意电量。 |
| 显微托架 | IV | 搭配通电的自动手术机进行符合条件的组织修复。需要无菌断指接合件。 |
| 免疫调节模块 | IV | 专科植入操作所用的器材。可随诊所后期进度取得，也可能出现在四级器材供应中。 |
| 医疗电源总站 | IV | 装入有电的兼容电池后，可向器材架上的设备供电。开始连续操作前检查余量。 |

### 原版供电与模组

M4、手动除颤器和工作站控制模块都可以装兼容的通用模组。模组窗口会显示当前摆法的加成，其他床旁机器按出厂设置运行。

| 原版物品 | 诊所用途 |
| --- | --- |
| 能量电池 | 放进兼容机器或医疗电源总站。初始有两块满电的 100 单位电池，分别配给 M2 和 AED。 |
| 电流转换器 | 可以装进兼容的单台器材。打开后按原版电价扣除信用点，需要店内供电正常且余额足够。 |
| 充能器 | 拆下能量电池后放进原版充能器，隔夜补电。替换和升级依照原版渠道。 |
| 性能模组、超频模组 | 按原版性能加成缩短操作时间。超频前看一下耗电变化。 |
| 效率模组、环保模组 | 按原版效率加成调整耗电。无加成时，手动除颤器每次充电耗电等于所选焦耳数除以 50。 |
| 质量模组、优化模组、精炼模组 | 按物品面板显示的属性生效。提高质量有助于手动除颤器转换心律，M4 也更容易读到信号。 |
| 神经核心模组（受限）、神经核心模组（无限制） | 装入兼容模组槽，应用原版性能、效率和质量属性。 |
| 报废模组、损坏模组、节点（小）、节点（中） | 装配限制和效果按原版模组面板判断。购买前可先看外形、类型和提示。 |

## 诊所用药与无菌耗材

药商带来的批次会轮换，买之前可以比较纯度。诊所开张时有广谱抗感染包、补糖包和无菌注射器。先装好注射盘，再把药包与注射器放在能取到的地方。查看物品或在床边确认剂量时都能看到批次纯度。用药后先复查，再决定是否要补用。

| 物品 | 床旁用途 | 怎么取得 |
| --- | --- | --- |
| 广谱抗感染包 | 用于检查后符合条件的感染。 | 向药商购买，或用一份抗感染药提取物在配制台封出两包。 |
| 补糖包 | 游戏内确认血糖偏低后使用。补糖后可复测血糖变化。 | 向药商购买，或用一份补糖剂提取物封出两包。 |
| 补液包 | 用于符合条件的输液、循环或电解质支持。 | 向药商购买，或用一份补液剂提取物封出两包。 |
| 循环支持包 | 适用于部分需要循环支持的情况。使用后留意血压和病人反应。 | 向药商购买，或用一份循环支持剂提取物封出两包。 |
| 肝素 | 用于符合条件的冠脉治疗。 | 三级起可从药商处买。四级配方使用补液包和至少 95% 纯度的循环支持包。 |
| 舒痛片 | 符合条件时可缓解受伤后的不适，也可作为带回家的处方。 | 向药商购买，或在配制台用一包至少 90% 纯度的循环支持包制作。 |
| 诊所生物凝胶 | 用于部分已安排的血管恢复治疗。 | 四级在配制台用一份罗非鱼植皮片和一包至少 90% 纯度的循环支持包制作。 |
| 升压桥接剂 | 三级复方药，短时间支持血压。使用后看血压和心律。 | 三级起向商贩购买，或按下方配方制作。 |
| 稳律缓冲剂 | 四级复方药，用于已记录的心律反复。使用后可能出现血压下降。 | 四级向商贩购买，或按下方配方制作。 |
| 肾上腺素 | 四级急救药包，在严重循环衰竭时提供短时间支持。 | 四级向商贩购买，或按下方配方制作。 |
| 无菌注射器 | 确认使用符合条件的药包时消耗一支。 | 入门物资、药商，或在配制台用两份霜藻条制作两支。 |
| 无菌手术包 | 符合条件的引流、浅表异物清理或修复需要这一耗材。 | 三级起留意器材商的轮换货品。 |
| 密封取物盒 | 自动手术机取出符合条件的残留异物时使用，一次一盒。 | 四级留意器材商轮换。 |
| 无菌断指接合件 | 显微托架所需的一次性接合件。 | 四级留意器材商轮换。 |
| 无菌药筒 | 稳律缓冲剂和肾上腺素的配方耗材。 | 四级在配制台用一包未拆封的普通或管制医疗用品制作两个。 |

## 种植与加工

解锁农夫后，可以向退休农夫买诊所作物。给水培系统装电池、加水、放入种子，隔夜生长。收获时会返还种子。用原版 DNA 编辑器和 DNA数据盘可以在兼容作物之间转移特性，诊所作物的默认特性各有取舍。

| 种子或孢子 | 收获物 | 默认特性与主要用途 |
| --- | --- | --- |
| 脉藤种子 | 脉藤嫩梢 | 长得快，也更耗水。用来做循环支持剂提取物。 |
| 月苔孢子 | 月苔叶 | 耐脏水，产量偏低。用来做抗感染药提取物。 |
| 霜藻孢子 | 霜藻条 | 耗水少，对杂质更敏感。用来做补液剂提取物或无菌注射器。 |
| 糖荚种子 | 糖荚仁 | 产量高，长得慢。用来做补糖剂和补液剂的提取物。 |

诊所制药需要同时解锁农夫和化学家。先在搅拌机的容器槽放一个空量筒，加工后查看容器里的成分。把处理好的容器装进化学制剂成型机，选对提取物再点出料。每份成品用掉 2 mL 混合物。要封成药包，再把提取物送进无菌配制台。

| 提取物 | 游戏内加工步骤 |
| --- | --- |
| 循环支持剂提取物 | 搅碎一份脉藤嫩梢，用滴管加 1 mL 游戏内的碱性溶液，再用加热板低档加热到 55 °C。加热前可加 2 mL 脉稳载液，让混合物生成精制成分。 |
| 抗感染药提取物 | 搅碎一份月苔叶，加 1 mL 游戏内的酸性溶液，再用低档加热到 45 °C。加热前可加 2 mL 无菌澄清液，生成精制成分。 |
| 补糖剂提取物 | 搅碎一份糖荚仁后用低档加热到 65 °C。用装有韧棉织物的干净水罐过滤，带着过滤后的水罐去成型机。加热前可加 2 mL 无菌澄清液，生成精制成分。 |
| 补液剂提取物 | 搅碎一份霜藻条和一份糖荚仁。处理容器和空馏出液容器分别放进有电的蒸发器，留一晚。取原容器里的干燥残留物去成型机。要取得稳定成分，先加 2 mL 脉稳载液，低档加热到 40 °C，出现稳定霜藻盐后再移入蒸发器。 |

| 试剂瓶 | 用途 |
| --- | --- |
| 无菌澄清液瓶 | 可用滴管取用，加入相应的游戏内作物批次。升压桥接剂和肾上腺素各需要一整瓶。 |
| 脉稳载液瓶 | 可用滴管取用，加入相应的游戏内作物批次。稳律缓冲剂需要一整瓶。 |

双击一包自有的**医疗用品（普通）或医疗用品（管制）**并确认，可以各取出一瓶 10 mL 的试剂。做无菌药筒时要另留一包未拆封的医疗用品。配复方药前检查试剂瓶，配方只收满瓶。

### 复方配方

| 成品 | 等级 | 放进无菌配制台 |
| --- | --- | --- |
| 升压桥接剂 | III | 一份含精制脉藤成分的循环支持剂提取物、一份含稳定霜藻盐的补液剂提取物、一整瓶无菌澄清液。 |
| 稳律缓冲剂 | IV | 一份含精制脉藤成分的循环支持剂提取物、一份含精制月苔成分的抗感染药提取物、一整瓶脉稳载液和一个无菌药筒。 |
| 肾上腺素 | IV | 一份含精制脉藤成分的循环支持剂提取物、一份含精制糖荚成分的补糖剂提取物、一整瓶无菌澄清液和一个无菌药筒。 |

配制台会核对两份提取物的实际成分和检测结果。药品纯度取两份提取物中较低的一项。制作完可以在物品详情里查看用了哪些原料批次。

### 原版加工器材

| 原版物品 | 在制药流程中的用途 |
| --- | --- |
| 水培系统 | 供电并加水后，让诊所作物隔夜生长。 |
| DNA 编辑器、DNA数据盘、基因稳定模组 | 提取、转移或去除兼容特性。用基因稳定模组可以保留供体，降低一阶特性。 |
| 搅拌机、25 毫升量筒、50 毫升量筒、100 毫升量筒 | 将作物加工成可量取的混合物。量筒的提示会列出成分和残余水量。 |
| 加热板、化学设备模组 | 给游戏内的作物混合物加热。原版化学模组可以改变机器档位和加热表现。 |
| 蒸发器 | 原容器留下干燥残留物，馏出液收进另一只容器。 |
| 化学制剂成型机 | 把处理过的混合物制成提取物。干料配方要等容器成分里的水消失后才能出料。 |
| 水罐、韧棉织物 | 在罐里装滤布，过滤处理过的糖荚混合物。 |
| 1 毫升滴管、5 毫升滴管、酸性溶液瓶、碱性溶液瓶、化学用品（普通） | 用滴管在量筒里添加定量试剂。拆原版化学用品可补充试剂。 |
| 化学手册、水培农业手册 | 查原版机器操作与种植规则。 |

## 可配合诊所使用的原版物资

原版物品仍可通过正常的购买、赠送、搜刮与人脉渠道获取。柜台也可以继续卖药。床旁使用前会先让你确认，实际消耗对应的自有批次。

| 原版物品 | 诊所用途 |
| --- | --- |
| 基础绷带 | 床旁也叫「普通绷带」。可给符合条件的出血或烧伤做敷料，价格较低。开诊时送两件。 |
| 止血绷带 | 给大量出血的部位包扎时更快。开诊时送一件。 |
| 外用药膏绷带 | 敷料本身还有浅表伤口护理作用。看部位和伤势选择。 |
| 血袋 | 普通输血耗材。三级起药商会带血袋，库存少时有机会多带一袋。 |
| 一袋“蓝血” | 用于检查后符合条件的血管支持，和普通输血是两项不同的操作。四级器材商可能带货。 |
| 南丁格尔软膏 | 检查过的浅表擦伤可以使用。 |
| 医用酒精 | 符合条件的浅表伤口可以选用，作外部清洁。 |
| 罗非鱼植皮片 | 用于符合条件的伤口护理，也是四级诊所生物凝胶的原料。 |
| 植皮罗非鱼卵 | 三级起可给检查过的擦伤用未受精鱼卵。受精卵留作繁殖。 |
| 外科手术工具套装 | 符合条件的异物清理与瘢痕处理可用这套工具。工具可重复用，另备需消耗的无菌材料。 |
| 水质检测试纸 | 有相关水源疑虑时，可用未使用的试纸为符合条件的病历补一份物证。 |
| 奥克西莫注射器 | 二级起可在监护下给检查过的特定伤情止痛。接好心电导联和指夹，用药后留意呼吸。 |
| 奥克莫吸注射器 | 二级起可作为监护下的止痛选项。沿用原版获取渠道。 |
| 纳洛通注射器 | 用于已有相应暴露证据的急救。用药后继续观察呼吸和反应。 |
| 赛纳普斯注射器 | 三级起，在符合条件且病人同意的复诊中可提供恢复支持。 |
| 免疫宁注射器 | 确认是真品后，可在符合条件的专科治疗中提供暂时支持。 |
| 噬菌霉素片 | 符合条件的稳定感染可以用药，或在离诊时开药带回。开诊时送一片。 |
| 无证噬菌霉素片 | 可做原版柜台交易，报价时可能涉及来路。床旁确认用的是有证药品库存。 |
| 医疗用品（普通）、医疗用品（管制） | 拆开得到两种诊所试剂，保留密封可做无菌药筒，也可以做原版采购交易。 |
| 医疗舱物资箱、一次性钥匙卡（医疗） | 用对应钥匙卡打开物资箱。原版物资之外，有机会找到诊所设备和耗材。 |
| 成分光谱仪、免疫宁检测指南 | 按原版方式检查药品批次。报告说的是药品成分，病人的体征要在床旁检查。 |

### 柜台交易和暴露线索

这些原版物品可以出现在交易请求或病史里。病历可能录下标签或目击者的说法，给下一步检查提供线索。

| 物品 | 用途 |
| --- | --- |
| 避孕药 | 可以在原版柜台按私密购药需求出售。 |
| 咖啡因药片、一板零嚼 | 可做原版交易。询问近期摄入时也可能成为线索。 |
| 嗅盐 | 原版急救用品，也可能出现在目击者的说法里。 |
| 一小瓶“梦尘”、芬太片 | 原版贸易物品，也可能出现在暴露病史里。 |
| 梦魇帽菇、一小瓶“梦魇尘”、山奈德片 | 这些原版物品可能从暴露史中辨认出来。 |
